## 现场恢复

目标机接入后，先保留覆盖安装前的原版本。DEVICE_SERIAL 取自 adb devices -l，FIELD 为此次现场的独立目录，APK 为上表 B08 安装包。

~~~bash
adb -s "$DEVICE_SERIAL" shell getprop ro.product.model
adb -s "$DEVICE_SERIAL" shell dumpsys package com.starcore.research.r13 > "$FIELD/device-before-upgrade.txt"
adb -s "$DEVICE_SERIAL" install -r "$APK"
~~~

按原任务书在完整预登记日历的开始和结束分别运行原采集器，保留它写出的原始文件、偏好投影、设备时钟和同一快照。用同一 APK 贯穿三次导出、24 小时及 72 小时采集。终审命令需同时传入 --deliveries、--require-full-closure、--start、--end 和 --window-bundle。[原施工任务书](https://github.com/gtt46461-star/starcore-public-build/blob/6d23ddc26e2a827daca7efaf55801e90ccd5feb6/construction/plans/STARCORE_R33_5_REVIEW_20261119/CODEX_EXECUTE.md)
