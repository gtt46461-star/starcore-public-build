## 已有实际实现的更新

- 用数据库结构指纹复用已通过的迁移，避免每次启动重复备份/DDL；结构不同仍执行验证。
- 增加版本、进程、1分钟节奏纪元，只用纪元后实际开奖作为覆盖分母；首期和稳态性能分别统计。
- 固定顶部后台能力状态条，显示电池/闹钟/通知能力，点击进入设置；返回后重新读取。
- 新增逐次 HTTP 请求账本，记录开始、响应时间、HTTP码、响应hash、业务接受/拒绝；接口参数和密钥不写入该账本。
- 增加每期抓取→分析→预测→结算→FULL查询，首页20期、详情500期和CSV导出；独立影子总数与30/60/120期命中/Wilson。
- 保留首次淘汰原因、当时证据、期号与政策版本；不猜测已经丢失的历史原因。系统漏捕获继续观察；明确质量失败继续按证据淘汰。
- 增加候选可运行机会、调度选中、实际执行和系统预算让步记录，避免把轮转调度误判成算法质量差。
- 新结构预注册家族，历史候选归入保守旧家族；暂停、归档不减少假设数量。回填未完成时不授予统计通过。
- 算法、R906图资产、R915创生资产三个消费者共用独立120期观察及至少240期后续配对窗口；窗口允许5%/12%/20%/30%分级上限，消费者仍受原有更低上限约束。每期只采用一个研究消费者，贡献表记录实际权重；读取失败保留原排序。
- 32候选观察队列、每批最多8个算法，按最近实际冻结期轮转；历史证据最老优先，实时任务优先；显示净吞吐、积压ETA和最新FULL的实际期数差。
- 240原子冻结上下文质量账本：按独立期统计支持、方差、漂移、语义分区与相关冗余边；不把零值假装缺失，也不把相关性声称为因果贡献。
- 四大能力卡分工和详情独立；完整保留原趋势、形态、矩阵及其他既有资产。phone/sw600dp控件ID一致。
- 一键TXT检测报告包含Manifest、资源、按钮、逐文件清单与上述运行账本；源码改动有before/after行数、字符数、hash和完整diff。

## 新增训练与推理工具

手机“导出完整1200动作训练数据”导出真实持久化赛前快照，不在开奖后重建特征。

```bash
OPENBLAS_NUM_THREADS=1 python training/r925/pipeline.py --input /path/to/export.jsonl --out /path/to/new_trial
```

- 按期完整1200×96输入验证，严禁10候选代替1200、标签泄漏、非有限值、重复/逆序期号、冻结晚于开奖。
- train/tune/calibration/policy/sealed分离；至少5个扩展时间折；封存窗口登记防止换输出目录重复评估。
- 分组listwise与同一期hard-negative pairwise排序；选定动作后独立校准；policy提案不强行补出手配额。
- 新增D0/D1残差/D2双尺度/D3蒸馏，以及九专家Gate训练；完整保留旧R811模型。新模型采用明确的新输入合同 `R925_FROZEN_META96_ISSUE_MEAN_V1`，不冒充旧R811输入。
- 九专家logits从赛前1200动作中保存的线性meanRaw精确反解，训练时验证全部120个组合可重构；不重新读取未来数据。
- Android源码包含 `DeepCandidateRuntimeR925`，可读取生成的R811格式二进制研究模型，执行相同推理、PIT校验和Sinkhorn检查。
- 输出分域研究校准、独立样本支持门、十类失败观察、最近获胜反事实动作、模块消融、96维特征相关分析与模型hash。

训练包默认 `proven=false`，不会自动覆盖生产冠军。APK未装入模拟训练权重。这里没有当前游戏的真实生产训练文件与连接的手机，不能伪造训练通过、真机parity、未来胜率或真实出手频率。
