# R922 全软件功能清单与唯一主链

## 一、唯一实时预测链

1. `AutoFetchService` 按限流策略获取 Binance1-PK10 开奖；主/备线路、去重、脏数据隔离。
2. `TargetIssueResolver` 唯一解析 `base_issue -> target_issue`，禁止错期。
3. `AnalysisSingleFlightR36` 保证同一时刻只有一个正式分析 Owner。
4. 赛前历史、PIT 特征、趋势/形态/状态/号码属性/位置关联/教师与反推矩阵只读取目标期开奖前数据。
5. `K3ActionSpaceEngine` 生成 `10 * C(10,3) = 1200` 个单位置固定 K3 动作，一个都不删。
6. 原主链专家、关系矩阵、形态状态、原子/因子、风险和稳定性形成基础排序。
7. 已认证创生资产、已认证创造算法可在严格限幅内调整排序；未认证候选贡献为 0。
8. `V51CandidateRealGateR915` 评估受控工程候选资格。
9. `DecisionGateEngine` 是唯一动作授权 Owner；Research、后台和 UI 无权造 BET。
10. `V51Repository` 同一事务写入预测、机会分母、创造贡献审计、可选真实交易和结算目标。

## 二、期开奖与结算链

1. 每个合法开奖建立 durable settlement task；
2. 有赛前预测的目标期必须精确结算一次；无赛前预测明确排除，不能混入命中分母；
3. `SettlementEngine` 写 REAL 结果和盈亏；
4. `OosAfterDrawWriterR36` 写严格 OOS 标签；
5. `SettlementPostCommitSidecarR909` 在核心结算提交后依次处理公式、算法、资产、Teacher 反哺；
6. sidecar 失败不能回滚核心结算；失败进入独立重试；
7. Deferred 证据把每期 100 号码和 1200 动作补齐，且不调用模型重算。

## 五、真实出手和统计

- REAL：只统计 `trades/action=BET/stat_scope=REAL_TRADE/result=WIN|MISS`；
- SHADOW：严格 OOS 影子观察，不计真实盈亏；
- raw score：仅排序分，未证明时不叫真实概率；
- 机会频率：R922 每个赛前预测一行，最近 120 行中 BET 占比；
- 15%：观察目标，不是配额；
- 胜率展示同时看样本 N、Wilson95 下界、Brier、ECE、Coverage、分块/Regime 和最长连挂；
- 每期最多一个未结算 REAL；禁止追单和补频率。

## 六、后台运行

- 前台服务常驻通知；
- UI 退出强制幂等重连；
- TaskRemoved、Boot、JobScheduler、Alarm 多路恢复；
- Fetch/Analysis/Settlement/Research/Deferred 分线程并有压力让路；
- Service/Teacher/Learning/Settlement 分别写心跳；
- Android 强行停止、系统省电和厂商自启动权限必须由用户设置，软件不能绕过系统。
