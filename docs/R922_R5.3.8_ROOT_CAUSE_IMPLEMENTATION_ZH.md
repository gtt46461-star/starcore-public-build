## 2. 对 3.5.7 检测报告的严格结论

R921 并非“完美完成”。报告中可确认的主要事实如下：

| 项目 | 3.5.7 报告事实 | 正确解释 |
| --- | ---: | --- |
| 报告长度 | 约 352 页 | 原始全文和 240 原子长表重复嵌入，不适合日常决策 |
| Coverage | 6/30，缺 24 | 报告沿用了旧版本激活边界，不能证明 R921 新链完整覆盖 |
| 计算 P95 | 4014ms | 主机/现有数据口径通过 5 秒目标，但仍需手机复测 |
| OOM | 0 | 该样本期内未观察到 OOM |
| 严格 OOS | 809 | 有统计样本，但不代表当前新版本已被单独证明 |
| REAL | 40 次，16 中 24 未中，40.00% | 样本命中率可展示；Wilson95 下界约 26.35%，不能宣称稳定 40% |
| SHADOW | 809 次，命中率约 31.89% | 与 REAL 口径必须分账，不能用于真实盈亏宣传 |
| 校准 | 有效样本 0 | raw score 不能冒充校准命中概率 |
| Deferred | 待处理约 811，动作证据停在 100/1200 | 旧 `updated_at ASC` 轮转导致很多任务各走一小步、很少真正完成 |
| 创造公式 | 9 个 | 有候选，不等于已获生产证书 |
| 创生资产 | 0 个 | 空实验室启动与阶段调度存在等待窗口 |
| 创造算法 | 6 个观察中、27 个淘汰、0 个认证 | 38%/45%/50% 等小样本原始命中率不足以接生产 |
| 生产贡献 | fallback 约 100% | 原有接入调用点存在，但没有已认证候选时贡献必须为 0 |
| 后台 | 心跳存在，Teacher/Learning 出现 UNKNOWN | 早退路径没有完整写泵状态；UI 退出时也可能因旧心跳误判而不强制重连 |
| K9 报告门 | `BetObservations=40|required=0|FAIL` | 报告规则错误：有合法真实 BET 不应失败，应逐条验证合同 |

报告中的 40% 是 40 次 REAL 的观察值，不是未来保证。任何为达到 15% 频率而直接放宽门槛的做法，都可能把 Wilson 下界、Brier、ECE、分块稳定性和 Regime 稳定性做坏，因此 R922 没有加入配额补单。

## 3. R922 已实施修复

### 3.1 真实出手频率：建立真正分母

新增 `ControlledCandidateOpportunityAuditR922`：

- 每个 R922 赛前冻结预测写入一条不可变机会记录，HOLD、SHADOW、BET 全部计入分母；
- 记录候选门是否合格、拒绝码、稳定性、第三边界、熵风险、治理候选、治理权重和最终动作；
- 与预测、贡献审计和可选 REAL 交易在同一个数据库事务内提交；
- 最近 120 个机会直接计算 `BET / opportunities`；
- 15% 明确为观察目标，不进入 DecisionGate，不产生补单债务；
- 低于 15% 时先看拒绝分布，再用已结算 Future-OOS 做门槛非劣证明。

### 3.2 真实账本：删除“必须零 BET”的错误报告门

新增 `ControlledRealContractAuditR922`：

- 允许真实账本中存在合法 BET；
- 逐条验证实时来源、REAL_TRADE、授权哈希、固定 K3、单位置、受控探针 lane、合同状态；
- 未证明阶段要求 `calibrated_p/final_p/authorization_probability` 为 0 或不可用，禁止用 raw score 冒充；
- 检查同一期重复真实动作和同时存在多个未结算真实动作；
- 检测报告 K9 改为 `invalid=0 / duplicate=0 / open<=1`。

### 3.3 创造能力：从“有候选”变成“逐期可证明接入”

新增 `ResearchMainlineContributionAuditR922`，每期记录：

- `PRODUCTION_FALLBACK`：没有证书，原主链不变；
- `GENESIS_NEW_CERTIFIED`：创生资产通过完整证书后，以最多 8% 有界残差影响排序；
- `INVENTED_ALGORITHM_CERTIFIED`：创造算法通过完整证书后，以有界权重影响 1200 动作排序；
- `FORMULA_DSL_ACTIVE_SHADOW`：公式候选只在影子主链评估，不能直接推动真实 BET；
- 候选 ID、中文机制名、应用状态、权重、Future-N、命中率、Wilson、Brier、ECE、Coverage、配对样本/增益、FDR 和证据哈希；
- `direct_real_authority=0` 为数据库硬约束；改变排序后的第一动作仍必须经过唯一 `DecisionGateEngine`。

`CertifiedResearchMixerR915` 和 `AlgorithmProductionGovernorR915` 已补齐主链贡献证据字段。资产/算法不是凭 38%、45%、50% 的原始短样本直接接入，必须至少满足：

- Future-OOS N ≥ 240；
- 配对主链 N ≥ 120；
- 命中率、Wilson 下界、Brier、ECE、Coverage；
- 分块最差值、Regime 最差值、最长连挂；
- 配对主链增益和多重检验 FDR；
- 训练截止期严格早于使用期；
- 证书、结构哈希、行为哈希和状态哈希一致。

### 3.4 深度学习、动态迭代和创造面板不再“看起来固定”

新增 `ResearchEvolutionDeltaR922`：每个自主研究脉冲前后比较并持久化：

- 公式资产数/认证数；
- 创生资产数、Future-OOS 累计、认证数、状态更新数；
- 创造算法数、Future-OOS 累计、挑战者数、状态更新数；
- FTRL 更新数和 TinyDeep 更新数；
- 本轮是否真实发生材料变化及最近一次真实变化时间。

新增 `ResearchDynamicBootstrapR922`：当算法或创生资产表确实为空时，在低优先级 Research 线程中做一次受实时压力保护的启动；正常进化仍由六阶段调度负责。它没有任何 REAL 权限。

`ModelLearningActivity` 在前台每 15 秒读取同一 `RuntimeTruthSnapshotR906`，不另造统计。若没有新期开奖/结算/学习，数值保持不变是正确行为；有真实更新时会显示前后差值和时间。

### 3.5 因子、原子、分子与底层创造边界

R922 保留 240 个逐项登记的底层原子和 72 个导航家族：

- 165 个生产评分语义原子；
- 40 个 Research Proxy，只能研究，不可制生产证书；
- 15 个审计/身份原子；
- 20 个开奖后结算证据原子，禁止赛前泄漏。

原子运行时由 `GenesisAtomicWorldR920` 物化为有名字、有范围、有窗口、有 lag、有最小支持、有泄漏策略和更新时间的数值；A9 开奖后证据在赛前必须为 0。创生资产通过结构基因、状态记忆、条件分流、非线性组合和失败向量产生，单纯改几个参数不算新算法。

### 3.6 延后 100/1200 证据真正收敛

`DeferredEvidenceWriterR36` 从旧的更新时间轮转改为“最新目标优先、已完成核心优先、动作游标最深优先”。一个任务会连续推进到 1200 动作并终结，再处理下一项；后台空闲时最多批量推进，实时分析存在时立即让路。报告新增 backlog 的待处理、已完成、核心完成、动作游标深度和最新/最老目标。

### 3.7 后台退出恢复

- MainActivity 离开时改为强制幂等 `reconcileAutoFetchService`，不再因旧心跳看似正常而跳过；
- `onTaskRemoved` 请求完整链重连并重挂 Job/Alarm watchdog；
- 结算泵和学习泵在成功、让路和异常路径都写真实状态；
- 前台服务、`stopWithTask=false`、BootReceiver、JobService、Alarm、WakeLock 继续保留；
- Android 设置中的“强行停止”以及厂商电池管控是系统权限边界，应用不能绕过，必须在手机上授权自启动和无限制电池。

### 3.8 检测报告和顶部界面

- 日常按钮输出“R922 决策版报告”，只嵌入有界摘要，不再重复 240 原子长表；
- 第二按钮输出“取证原始附录”，需要时保留全量原始证据；
- 两种报告都提供 SHA-256、字符数和来源通道；
- 顶部标题限制一行，副标题/说明限制两行；
- 构建版本徽章移到独立横向滚动条并强制单行，修复截图中一字一行的竖排问题。

## 5. 不能伪装为已完成的物理和统计证明

- 未在用户手机上真实运行前，冷启动、息屏数小时、划掉任务、厂商后台限制只能标记 `RETEST_REQUIRED`；
- 覆盖安装不能自动改写旧历史数据，R922 新机会分母从首个 R922 冻结期开始；
- R921 的 40 次 REAL 命中率 40% 不能证明 R922 未来胜率；
- 没有足够的 R922 已结算 Future-OOS，不能宣称“胜率绝对不会掉”或“必定达到 15%”；
- 正确做法是先保护当前门，再通过机会漏斗定位拒绝原因，只对已证明非劣的单项门槛发布后续变更。
