# 检测报告 V2 必增章节

当前报告运行/研究证据非常多，但缺少用户要求的“整个软件每层都检查”。

新增：
1. APP_IDENTITY_AND_BUILD
2. ANDROID_MANIFEST_AUDIT
   - permissions / runtime-granted / activities / services / receivers / providers / exported / FGS type
3. RESOURCE_INVENTORY
   - 资源文件总数、sha、重复hash、孤儿、缺引用、变体一致性
4. LAYOUT_AND_UI_CONTROL_AUDIT
   - 每个layout ID清单；phone/sw600dp差异
5. BUTTON_WIRING_AUDIT
   - button id -> Activity -> click handler -> action -> runtime proof
6. UI_RUNTIME_VISIBILITY_AUDIT
   - 首页是否能看到后台/fetch/analysis/settlement/shadow/research
7. SOURCE_FILE_AUDIT
   - 545 Java逐文件行数/字符/hash/静态flag/Owner/是否在active call graph
8. ARTIFACT_ASSET_MANIFEST
   - training scripts、模型artifact、research assets、DB schema、release files
9. DATABASE_SCHEMA_MIGRATION_AUDIT
10. BACKGROUND_CAPABILITY_AND_PHYSICAL_TEST
11. PER_ISSUE_PIPELINE_LEDGER
12. SHADOW_OBSERVATION_STATS
13. REAL_CONTRACT
14. MODEL_ARTIFACT_PROOF
15. RESEARCH_FUNNEL
16. PRUNE_REASON_LEDGER
17. CERTIFICATE_LEDGER
18. PERFORMANCE_COLD_VS_WARM
19. DEFERRED_BACKLOG
20. PACKAGE_INTEGRITY/SIGNATURE/RESOURCE_ID_PARITY

规则：
- 没数据=N/A/NOT_PROVEN，不得当0或PASS。
- 静态PASS不能冒充真机PASS。
- 报告必须有“总问题表”，P0/P1/P2与具体文件一一对应。
