## 自动降噪
不能“删掉原子”，而是：
ACTIVE / WATCH / SHADOW_ONLY / QUARANTINED。
触发QUARANTINED：
- PIT失败
- 非确定性
- 数据源不稳定
- 高缺失
- 长期消融有害
但保留历史证据。

## 新原子准入
必须：
signed schema
deterministic
PIT safe
cost bounded
support definition
failure contract
unit test
parity
之后才能进入生产评分语义池。

## 目标
不是原子越多越好，而是让创造系统知道：
“哪些基础构件真的有信息、哪些重复、哪些组合互补、哪些只增加噪声”。
