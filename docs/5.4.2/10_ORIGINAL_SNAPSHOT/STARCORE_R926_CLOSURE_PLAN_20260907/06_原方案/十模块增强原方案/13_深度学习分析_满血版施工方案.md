# 深度学习分析：满血版施工方案

## 1. 三层角色
### Offline Deep Model
大网络只离线训练：
- 96→64→32→100 baseline
- residual MLP challenger
- distilled ensemble challenger
输出10×10 logits → Sinkhorn。

### On-device TinyDeep
ResearchTinyDeepLearnerR909：
- 只用已结算strict OOS逐期更新；
- trainedUntil=t，只能score t+1；
- SHADOW_ONLY；
- 记录loss EMA、updates、artifact hash。

### On-device FTRL
ResearchAdaptiveLearnerStoreR811：
- 轻量在线残差学习；
- 仅从frozen predraw + exact settlement更新；
- 不能回填Future proof；
- 作为sidecar feature/score，不自动接生产。

## 2. 增加“深度分析”而不是只增加更新次数
每个深度模型必须输出：
- 数据窗口
- 训练截止issue
- OOS fold metrics
- feature attribution proxy
- expert disagreement
- calibration
- drift
- regime
- paired vs champion
- 最近模型是否改善

UI不能只显示“TinyDeep更新839次”，要显示“更新有没有效果”。

## 3. 模型选择
同一数据同一fold比较：
D0 baseline
D1 +FTRL
D2 +TinyDeep
D3 +Teacher
D4 +Relation
D5 +Invented Algorithm
用paired issue-level结果选，不看训练loss决定生产。

## 4. 防过拟合
- Chronological split
- no issue shuffle
- early stopping只看validation
- sealed final一次
- random seeds固定并全部记录
- 超参搜索计入FDR/selection ledger
- 不允许训练集指标出现在“证明”栏

## 5. 模型漂移
Future live滚动监控：
- Brier
- ECE
- HR
- Wilson
- Regime
- PSI/feature drift proxy

PRODUCTION_INFLUENCE→SHADOW_ONLY，而不是继续硬用。
