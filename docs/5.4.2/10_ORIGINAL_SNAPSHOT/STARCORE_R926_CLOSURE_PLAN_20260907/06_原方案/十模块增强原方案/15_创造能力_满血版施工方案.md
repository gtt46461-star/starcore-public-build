# 创造能力：满血版施工方案

## 创造对象分四层
1. 原子：最小PIT-safe信息单元。
2. 公式：可执行组合表达式。
3. 算法Genome：观察+记忆+推断+更新程序。
4. 资产/方法图：多模块整体研究方法。

## 满血创造器
### Idea Foundry
从失败聚类、互补空白、Regime缺口产生研究题目。

### Structure Synthesizer
生成：
- memory topology
- interaction operators
- nonlinear transforms
- routing
- update program
要求结构哈希、行为哈希。

### Formula Synthesizer
不再随机混信号为主；
优先从：
- 高价值低相关原子
- 主链残差
- hard negatives
构造。

### Repair Synthesizer
专门修复N≥120的Elite候选。

## 质量优先搜索
每轮生成预算：
- 50% Elite repair
- 25% complementarity
- 15% new family exploration
- 10% calibration/risk repair
而不是100%随机探索。

## 候选必须有“十五器官”
Identity
Atomic provenance
Temporal boundary
Persistent state
Observation program
Inference program
Settlement update
Output semantics
Quality contract
Failure contract
Falsification
Resource budget
Lineage
Future evidence
Promotion explainability

## 创造成功的定义
只有达到CHALLENGER以上，才算“成功创造出有统计证据的策略”。
只是生成代码/名字/公式，不计成功。
