# M8：因果/反事实/消融 + 失败聚类 + 定向创造

## 目标
把“未中以后生成新算法”升级成：
先知道为什么错 → 再只修改对应机制 → 最后用paired OOS验证是否修好。

## 失败事件结构
每个MISS生成FailureCase：
- target_issue
- rank1 action
- actual
- third/fourth boundary
- entropy
- stability
- teacher trust/uncertainty
- trend/shape/relation
- regime
- active atoms
- feature attribution
- counterfactual nearest winning action
- missed number rank
- false-high-probability markers
- candidate contributions

## Failure clustering
按赛前信息聚类，不用未来数据：
F1 高熵
F2 低稳定
F3 第三边界脆弱
F4 Teacher误导
F5 Regime切换
F6 跨位关系假支持
F7 NumberQ排序错误
F8 Ranker近邻错误
F9 Calibration假高
F10 创造算法冲突

## 反事实
对同一期保持其他条件不变：
- 去掉一个模块/原子；
- 替换一个expert；
- 改一个候选结构；
重新计算影子排名，记录“如果没有它是否更好”。
只能用于下一期以后研究，不能改写当期预测历史。

## Leave-one-module-out
必须覆盖：
baseline
+FTRL
+TinyDeep
+Teacher
+Trend
+Shape
+Relation
+Invented family
逐期成对比较。

## 定向创造
每个新child必须写：
repair_target = 具体failure_cluster
parent_id
changed_module
changed_atoms
expected_effect
falsification_rule

禁止“NO_FAILURE_VECTOR”大量盲造；没有足够失败证据时宁可不生成。
