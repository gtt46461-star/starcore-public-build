# STARCORE_TIANSHU R924：第9/第10增强项“满血版”施工方案包

基线：
- App：V57.21.0-R5.4.0-924
- Package：com.ethk3.novaonepro
- DB：binance_k3_nova_one_pro_v57.db / DB_VERSION=36
- 固定红线：单位置、固定K3、每期最多一个REAL；禁止K4、动态K、多位置REAL、追期、马丁、加倍、频率债务。
- 唯一REAL授权：DecisionGateEngine_ONLY
- 唯一结算：SettlementEngine_ONLY

本包只强化两个核心问题：
1. 第9项：为什么一直创造不出“经证明的高胜率、高稳定、高品质策略方法算法公式”，以及如何重构训练、评估、创造、淘汰、挑战者、证书与主链接入。
2. 第10项：深度学习、动态迭代、创造能力、分子/原子/因子怎样做到“工程满血”，并把研究成果真正变成可验证、可证书化、可受控接入实时出号的生产能力。

重要真实性边界：
- “工程满血”可以通过代码、数据表、测试、哈希、PIT、parity、生命周期和真机证据完成。
- “高胜率/高稳定”不能靠代码宣称，必须由冻结后的严格Future-OOS证明。
- 不允许把开发回放、小样本、高拟合、开奖后特征、旧证据复制给子代来伪造优势。
- 本方案目标是最大化发现、验证和安全利用真实预测优势的能力，不承诺固定胜率或盈利。

先读顺序：
01 → 02 → 03~12（十模块）→ 13~17（四大能力与主链闭环）→ 18~22（施工矩阵/DB/验收/证据）。
