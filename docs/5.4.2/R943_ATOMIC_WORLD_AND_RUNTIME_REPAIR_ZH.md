## 逐期训练怎样执行

1. 主链先完成本期决定和不可变快照，研究工作使用已有低优先级线程。
2. 研究名单固定目标期、输入哈希、候选身份与结构；每页最多 32 项，已完成前缀可以提交。名单未完整发布时不能执行其中的半成品记录。
3. 算法、创生资产、公式和神经候选共享名单。所有仍可执行、依赖有效的候选取得逐期评估机会，完成的候选独立提交，重试只处理未完成项。
4. 预测只在开奖前冻结。时间片耗尽后续做；如果当期已经开奖，记录系统缺口，不重新计算一个“开奖前预测”。
5. 开奖后，算法 VM 的状态更新、创生资产的状态更新分别与对应标签在同一事务提交；失败一起回滚，重试不重复更新。
6. TinyDeep 从严格压缩标签按时间顺序学习。原子网络有自己的结构版本、输入、权重和训练游标。静态公式本身的可执行结构不会凭空产生权重；它逐期接受结果评价，并由独立校准器学习分数到概率的关系。
7. 生命周期根据真实冻结、配对结果和固定窗口判断观察、暂停、淘汰、隔离与晋级。系统没及时计算不能被包装成算法质量失败。

手机算力或后台暂停可能造成某一期没有完成所有评估。本次实现的是可恢复的逐期执行队列和真实缺口记录；不能保证任何设备在任何负载下都完成无限数量候选。

## 原子世界的实际结构

原子世界是软件中的可计算特征、带类型的运算、状态记忆与资产依赖，不是把物理原子概念直接套成预测能力。

现有注册保留 240 项身份：165 项允许生产前计算评分、40 项研究代理、20 项开奖后证据、15 项审计身份。后三类不会混入新原子网络的赛前评分输入。72 类资产的登记与依赖描述继续保留；实际新资产由可执行 VM、类型检查和依赖追溯约束。登记数量不表示 72 类都已产生通过效果验收的实例。

| 层级 | 实际计算与产物 | 质量判断 |
|---|---|---|
| 时间和来源 | 历史截止期、缺失掩码、连续性、时效、输入哈希 | 超前输入和被修改的冻结记录拒绝训练 |
| 坐标与动作 | 位置、号码关系、K3 集合、替换边界和动作几何 | 必须对应本期固定位置和三个不同号码 |
| 时间结构 | 多尺度频率、遗漏、事件间隔、持续时间、恢复和变化 | 必须由截止上一期的实际历史计算 |
| 图和交互 | 迁移、共现、排斥、路径、残差、乘积、差分等 | 类型合法、依赖完整、可重放 |
| 信息和状态 | 条件支持、集中度、熵、记忆、慢快状态、风险 | 区分真实值、缺失值、研究代理和开奖后字段 |
| 分箱工具 | 每个可评分原子的五个分箱，使用过去样本估计命中概率 | 本期的工具输出先冻结，开奖后才更新统计 |
| 原子神经学习 | 七组输入 → 16 → 8 → 1；七个逐组屏蔽输出 | 保存模型哈希、训练截止期、损失和未来逐组增益 |
| 新资产选材 | 原子未来增益排序、多原子组覆盖、既有可执行基因组 | 证据足够时选择研究父材；不足时明确为探索材料 |

七组神经输入分别汇集上下文与坐标、时间、关系图、数值算子、统计信息、状态记忆、不确定性与动作结构。缺失项被掩码；全缺失时不更新网络。

每期只取一个事前独立选定的动作上下文，避免把同一期高度相关的 1200 个动作当成 1200 个独立样本。165 项原子都从该期真实结果得到质量统计，网络使用同一事前冻结输入进行顺序更新。历史压缩、数据库清理不会把训练次数重置，也不会把保留的累计次数解释为当前还保存着同样多的原始记录。

## 怎样保留、暂停和淘汰

原子工具记录可用样本数、缺失数、分箱计数、相对既有边际基线的 Brier 增益、方差、120 期分块结果、最近状态。状态有：

- `OBSERVING`：证据不足或增益尚不明确。
- `RESEARCH_PARENT`：至少 240 个事前冻结的未来标签，增益下界为正，并通过完整的正增益分块要求；可以优先供给新资产选材。
- `MASKED_MISSING`：缺失超过允许比例，不能当作完整输入。
- `RETIRED_NEGATIVE_UTILITY`：证据支持该工具的边际效果为负，退出优质父材选择。
- 既有原子隔离机制还会因不确定重放、时点或依赖错误隔离节点及受影响后代。

统计置信下界用于研究排序，不构成同时比较 165 个原子的生产效果证明。单个原子边际效果差，也不自动证明它在所有非线性组合中无用。因此保留最小质量记录与依赖身份，避免物理删除导致已有模型无法解释；过期的大体积逐期数据则实际删除。创造出的完整算法仍通过自己的独立未来样本、校准、配对和多重比较门验证，不能继承父材的样本数或证书。

## 35% 与主链接入

35% 是候选准入的一项门槛，不是对未来胜率的保证。达到命中率后，仍检查 Wilson 下界、Brier、ECE、未来和配对样本、独立窗口、校准版本、模型/特征依赖、资源预算和实际执行审计。统一证书的完整受控影响测试使用 360 个未来及配对样本、两个独立窗口；逐步参与的实际权重由证书计算。

旧算法的可执行结构、已训练记忆和已有证据保留。符合当前契约、有效期和证据条件的候选可以参与后续主链；仅在历史开发集表现好，不能直接改成已经通过未来验证。更改输入、模型或证书依赖后，旧证据若不再兼容，应说明失效原因并进入新的观察流程。

## 手机储存治理

- 开奖和按期的普通证据最多保留 5000 期。模型、注册身份、累计质量摘要保留。
- 重复的大型动作、号码、排列明细保留 120 期；压缩快照和普通证据的保留上限仍为 5000 期。
- 通过现有数据库写入通道分批删除。大型 B03 表按固定游戏分区利用原有索引，并在时间预算内连续清理小页，避免每页重新排序全表。
- 原不可删除触发器只对超过上述保留范围的记录开放清理；范围内仍拒绝删除，修改保护保留。
- 新库配置增量回收和 WAL 大小策略；旧库在满足空闲条件、存在足够可回收页且有临时磁盘空间时执行一次压缩。临时空间不足、WAL 忙或 SQL 失败会留下明确状态。
- 自动生成的诊断缓存最多三个、总量约 48 MiB，并保护当前导出文件；不会删除用户另存到其他目录的文件。

覆盖升级后的老库通过后台分批清理，不是点击安装即瞬间缩小。大库的一次性压缩耗时与磁盘速度、剩余空间有关；本次没有用户手机旧 10 GB 数据库，不能给出实测缩小量或宣称闪退已全部消失。
