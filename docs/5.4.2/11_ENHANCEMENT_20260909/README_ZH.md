## 高胜率、高稳定、高品质的共同口径

保留原目标：同一冻结政策、同一新增Future窗口，HR≥40%、REAL频率≥15%、ECE≤0.04。15%不是补单债，不得通过放宽质量或缩分母达标。状态区分ENGINEERING_PASS、OBSERVED_TARGET_MET、EVIDENCE_CONFIRMED、FAIL_EFFECT、INSUFFICIENT_EVIDENCE。确认级结论要求预注册联合置信界、相对基线和域稳定证据；点估计不是保证。

在各位置号码均匀且开奖对赛前信息条件独立的假设下，固定单位置K3命中率为3/10；复杂模型不能在该假设下制造信息优势。这是数学参照，不能当成已经验证的真实开奖机制。常数0.3概率在该假设下期望Brier为0.21，因此旧Brier≤0.24门单独不足以证明优势；保留旧门，同时增加对冻结champion、常数0.3及简单模型的配对Brier/NLL技能和区间。

每期1200动作只算一个issue单位。计划1200期、15%出手时仅约180个选中标签；不能把1200当命中率样本数。样本预算须在看Future前结合效应、方差、依赖、多重比较和最大日历冻结。历史最大连错不保证未来上限，分箱区间和conformal覆盖不保证某期命中。
