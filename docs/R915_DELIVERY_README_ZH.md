## 本次真正解决的四条主问题

1. 后台：普通返回桌面、任务划走或进程被系统回收后，由 `START_STICKY + Alarm + Job + BootReceiver + 内部看门狗` 重新拉起并执行业务对账。Android 设置里的“强行停止”属于系统硬封锁，任何普通 APK 都不能自行绕过，用户再次打开应用后才会恢复。
2. 结算：每个抓取到的有效开奖都先产生持久化任务；当前期开奖使用有界即时重试，历史欠账公平回补；OOS、REAL 交易结果和任务终态由唯一 `SettlementEngine` 在同一事务提交。没有赛前冻结的期不能开奖后伪造预测，而会明确进入 `NO_PREDRAW_CANONICAL_TERMINAL`。
3. 真实出手：解除全局硬锁，加入精确签名的受控候选门。只有原始概率、动作稳定性、时间、唯一未结 REAL、完整授权哈希等全部通过才写入唯一 Trade；不满足时真实显示 HOLD/拒绝码。Research 不能直接授权 REAL。
4. 深度学习、动态进化与创造：保留原有资产主链，新增 240 L0 原子、72 个导航家族、15 器官新资产生命体和 16 器官算法生命体；每期赛前冻结、开奖后 exactly-once 更新、中文机制命名、结构/行为去重、多指标 Future OOS 晋级与自动淘汰均已接入。只有有证书的新贡献可限幅影响 Production。
