# V57.20.8-R5.3.8-922 发布说明

R922 是 R921 的小版本严格闭环升级，重点修复 3.5.7 检测报告、真实频率分母、创造主链证据、后台退出恢复和窄屏顶部竖排。

## 主要新增

- R922 每期机会漏斗及 15% 观察目标；
- 非零 REAL 逐条合同审计；
- 公式/创生资产/创造算法逐期主链贡献审计；
- 创造候选完整 N/HR/Wilson/Brier/ECE/Coverage/Paired/FDR 证据；
- 公式、资产、算法、FTRL、TinyDeep 前后变化快照；
- 空研究实验室低优先级动态启动；
- Deferred 最新最深任务优先收敛；
- UI 退出和 TaskRemoved 完整链重连；
- 决策版/取证版双报告；
- 顶部版本徽章横向单行显示；
- 创造详情页前台 15 秒自动刷新。

## 兼容与安全

- 包名、数据库名和 DB_VERSION 不变；
- 使用与 R921 相同的发布证书，可覆盖安装；
- 固定单位置 K3，每期最多一个 REAL；
- Research 直接 REAL 权限保持为 0；
- 未加入追单、马丁、加倍、动态 K 或频率补单；
- 任何已认证创造候选仍必须经过 DecisionGate。

## 证明边界

工程编译、行为合约、APK 资源/签名/反编译门已通过。手机冷启动、息屏后台、厂商电池策略和 R922 新样本胜率必须安装后复测；发布不承诺随机开奖的固定胜率。
