## Startup integration

`SCHEMA_CONTRACT.json` is generated by invoking the actual frozen helper. `REVISION=1`; contract hash is `9a1c379d198f5a2dc5efc180dcdefce5fb67b4ba18612940b6c998d56000b5b9`. There are five tables, one index and 18 triggers. Root's versioned migration owner must invoke `ModelPublicationR31.ensureSchemaR31(SQLiteDatabase)` inside its transaction after SU2 and matrix metadata startup. `schemaObjectsR31()` supplies type/name pairs. `requireSchemaR31()` compares every complete DDL definition, including PK, CHECK and immutability/quota guards; startup also reconciles quota totals. Unknown definitions are refused. Business callers perform no DDL.

`SOURCE_SCOPE_PROOF.json` pins 15 unchanged numerical/kernel/codec source files and five unchanged producer compute/training segments against the base. `FAMILY_ROSTER_OBSERVATIONS.json` records read-only native SQLite counts for every one of the 23 executable families; prospective qualification and verified-improvement flags remain zero for all newly born attempts.

Old inline evolution, stage and matrix payloads remain readable. New references reuse the existing `ChunkedCheckpointR26` format and `CheckpointArtifactsR26.sha`; immutable 16 KiB SQLite fragments permit the existing SQLite-only readers and copied report databases to resolve them. The old evolution reference/bytes are retained in the publication plan. Preparation and restore use the production process `MemoryBudgetR31`; owner declarations are released after synchronous work actually exits. Declared bytes are not measured heap/native/PSS.

New protocol rows have trigger-enforced admission: 256 MiB conservative logical bytes, 32,768 fragment rows, 65,536 item rows, 1,024 publication roots. Same-value replay is not charged twice. A full protected ledger yields typed dependency and preserves existing data. Physical SQLite/WAL/index allocation, a shared 2/4 GiB quota, and eventual reclamation remain **OPEN**; logical accounting and a free-space floor do not prove full B05 storage admission. Immutable protocol artifacts are preserved pending a separately reviewed retention migration.

Other B02 work remains open: pre-existing ABI/WarmCandidate bulk preservation, candidate training-step/diagnostic fanout, legacy registration payloads, old compatibility-only bulk APIs, freeze/certify payloads, and broader owner resource/protection accounting. This change does not close all B02, B05, B06, or P03. Android scheduling, Android WAL hold P99, process memory peaks, natural quality, and 24/72-hour acceptance are **NOT RUN / NOT PROVEN**.

## Reproduce

Run `python3 verification/r31/evolution_publication/run_baseline.py` for the original named failure. Run `python3 verification/r31/evolution_publication/run_native.py` for the frozen 014 support comparison, or add `--shared` for the separately copied 4459-class support (`582f7475...fea56`). The runner uses JDK compilation and native SQLite JDBC, not Gradle, and snapshots production sources before compiling. Host adapters translate SQLite APIs into real SQL; Android JSON is the checked-in AOSP implementation.

Raw traces may be losslessly gzip archived. `ARCHIVE_INDEX.json` maps original paths and SHA-256 values to their compressed files. Each run receipt and every original failure is retained.
