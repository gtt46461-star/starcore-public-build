F09 records the filtered mixture of exact-permutation emission distributions, plus the actual emission-logit L2 penalty, before and after updating parameters at the identical pre-label filtering prior. Its reported gradient is the actual300-coordinate emission SGD gradient. Exit/stay parameters use an expected-count update for the next filtering prior; their actual changes are included in the full learned-parameter delta and are not labelled an SGD gradient. The new prior/posterior is temporal context, not a learned-parameter delta.

The independent test checks all300 logit derivatives in three causal contexts (fresh, learned, gap-reset),900 derivatives total, and verifies actual parameter changes, fixed-input loss, target-free input hashes, complete restore/next update, gap retention, cancellation and atomic rejection of corrupt state. `WireParity.java` compares every prediction, feature and full raw state against baseline `62fd2b7` for two300-update trajectories, including +/-7.99 near-clipping logits, gaps and restore. The raw codec is unchanged.

`F09-state-sample.bin` has typed metadata and SHA256. It is a synthetic isolated kernel sample, not a trained policy or natural-quality evidence.
