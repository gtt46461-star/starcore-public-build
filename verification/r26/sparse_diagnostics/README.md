F01 diagnostics measure the exact joint permutation NLL plus `0.0005 * sum(group L2 norms)` at the same pre-label lag context before and after the actual original proximal step. The gradient norm is a composite subgradient; at a zero group the regularizer's zero subgradient is chosen. The independent test inverts the actual nonzero proximal result and checks numerical directional derivatives, rather than treating the proximal parameter change as an SGD gradient.

`WireParity.java` runs unchanged against public baseline `9fdccbe` and the current kernel. All 32 cases cover lags 1–8, both cross-position modes, zero and tiny group weights, 160 updates, missing-context resets, observation-only input and restore. The digest covers every prediction, feature and complete old numeric checkpoint projection. New v3 records append an update counter and provenance; they are not byte-identical to v2.

An old v1/v2 context clock also counts observation-only events and resets on a gap. It does not authenticate a historical training count. Imported kernels retain their weights/context and explicitly report unknown previous update history, counting actual subsequent updates from zero. A new kernel's complete training counter survives gaps and does not count observation-only calls.

`F01-state-sample.bin` is a synthetic isolated kernel sample with typed metadata and SHA256, not a trained policy or natural-quality evidence. The production Foundry transport test separately verifies 128 committed full-precision immutable training rows and their real source/checkpoint manifests.
