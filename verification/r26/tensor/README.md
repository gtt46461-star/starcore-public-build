F19 has an explicit tensor-v2 policy with position/number/lag factors, optional causal prior-position state factor, complete AdaGrad slots and lifetime counter. The original abi=1 SGD executor/codec remains separate. Adding the state relation changes the executed graph; position/state removal controls cannot publish. A rank number is not counted as a new family.

`R26TensorMechanismTest` reconstructs dense tensor scores independently, checks all mode gradients by finite differences, compares before/after exact joint NLL on the same frozen pre-label frame, and checks full restore, next updates, gap context reset, canceled updates, corrupt restore and mismatched graph rejection. On the independent synthetic held-later set, state/full, no-state and no-position marginal NLL were 0.001173 / 0.693304 / 0.693592. IID results were both 2.302583. These are mechanism diagnostics; matched-cost dense controls and natural quality remain unaccepted.

`python scripts/verify_r26.py` runs this group and writes `build/r26/f19-tensor-state-sample.bin`. The sample is a raw kernel checkpoint (including optimizer), not a complete policy state or qualification. Its bound graph is tensor=2, position=true, state=FIRST_POSITION_HALF, optimizer=ADAGRAD_V1, control=NONE, lr=0.02. The CI artifact binds the source and numeric ABI.

Candidate and canonical terminal live updates commit immutable measured witnesses with their fenced checkpoint CAS. Each witness includes the sample ID/source kind/hash, actual optimizer update count, input digest, fixed-input objective, gradient and parameter L2 norms, before/after state commitments and the actual batch checkpoint. It grants no qualification. Unsupported kernels stay unmeasured. Up to 8192 details remain; omitted detail counts are folded. Superseded historical state files follow regular checkpoint retention and are not promised by a hash commitment alone.
