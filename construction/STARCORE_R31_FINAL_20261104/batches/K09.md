### R31-B06-C01 保留历史训练并统一冻结输入、角色和数据修订

### R31-B06-C02 回放增量化与模型、优化器、游标共同提交

卡片原文：[cards/B06/R31-B06-C02.md](../cards/B06/R31-B06-C02.md)。树内历史状态：IMPLEMENTING（只说明已有代码在哪里，不等于已验收）。

问题：已有 Foundry/Legacy/ModelReplay 数值实现需保留；卡顿与重启不能通过每次重跑数千期补救。模型状态与游标不一致会重复学习或假进度。

步骤：

1. 建立不中断执行的黄金输出，包括权重、优化器、RNG、游标、预测、act/K3 与评价。
2. 将每片上限设为最多 64 训练样本或 256 回放行，并受 B02 分片时间预算限制；这两个数是起始配置，必须在目标设备测量。
3. 在 DB 事务外计算并写临时 artifact、验证校验和；事务中校验 fence/source revision，再写引用、进度和收据。
4. 事务失败不 publish；重试读取已提交幂等键，不能对同一标签再训练一次。
5. 缓存归属按 dataset/job/model registry 记录；作业终止释放引用，持久 artifact 按证据角色保留，不把训练原始数据复制给每个候选。

### R31-B06-C03 AtomNet 十位置完整训练水位与真实发布消费证明

卡片原文：[cards/B06/R31-B06-C03.md](../cards/B06/R31-B06-C03.md)。树内历史状态：IMPLEMENTING（只说明已有代码在哪里，不等于已验收）。

问题：AtomNetSessionR30.online 按位置逐个更新，trainedThrough 与 trainedThroughOrdinal 可报告部分期已观测水位；ready 只判断 ONLINE。需要把部分完成与消费端可用完整模型分离。

步骤：

1. 写清消费端是单位置模型还是共享十位置模型；共享模型不允许用局部更新冒充完整期水位。
2. 每处理一个位置提交训练步与 nextPosition；第十位置提交时同时推进 completeIssue。
3. 维护独立的 publish receipt，包含 state hash、输入截止与已训练截止；预测冻结引用 publish receipt。
4. 对照学习率 0 模型保持不变是合法控制；非零学习率测试用有梯度样本证明权重、Adam 步数真实变化。
5. 把材料化原子、训练样本、训练 epoch、已发布模型、被实际预测消费的模型分别计数。
