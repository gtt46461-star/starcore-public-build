# P2.04 思路族、策略族、失败假设和短期窗口

## 根因与现场证据

4个旧SU1策略、24个旧专家提案不能说明现版产生了新品。82能力中F23教师缺绑定。

## 本批修改与事务边界

从连续失误按位置/状态分解校准、覆盖、窗口漂移；每项形成可证伪假设、对应 typed AST 编辑和禁用条件。保留多位置多号交集作对照，同期比较去窗口、去交集、延迟一个窗口。只把有效的因果短期状态送入下一期单位置固定K3生成。教师缺源仅挂本支，其他家族继续。

不同语法同一决策签名去重；只在DEV学结构与参数、SELECT排位；锁定留出后才评价。缺数据不得补齐成可预测信号。

## 本批验收与故障反例

输入常量、洗牌、含弱结构三组；固定预算测发现率与假阳性；打印每个族输入、操作、artifact及淘汰原因；拒绝读取当前标签或使用未来窗口。
