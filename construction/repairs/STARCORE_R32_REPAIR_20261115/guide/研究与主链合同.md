# 从开奖、创造到下一代和真实出手

## 一期怎样走完

实际存储优先复用现有表和owner。以下为逻辑键；落库用仓库中对应的键和事务，避免再建同义账本。跨报告比较先匹配源版本、安装身份、数据角色、目标期和水位。

|事件|必须持久化的关联和时序|中断后动作|
|---|---|---|
|可见输入与赛前冻结|market、target、base、每个来源knownAt、sourceRevision、policyHash/modelHash、冻结时间、单位置K3或HOLD；晚于截止的源剔除|唯一决策owner重读同一target的原冻结；迟到记MISSED，禁止回填。|
|开奖与结算|canonical issue、官方结果、来源hash、原冻结ID、角色、hit、结算时间；重复开奖只发同一收据|事务后ACK丢失时重读权威账，不再加hits或收益。|
|训练队列与误差|eventId、输入/标签可见序、role、上一checkpoint、旧模型预测、损失、更新后optimizer及新checkpoint|缺失标签暂存；保全合规历史样本，回放游标从最后提交恢复。|
|分析、出生与验证|失败机制/状态窗口、原子与矩阵hash、父代列表、typed程序、operator、代数、行为签名、数据段与冻结配置、弃用理由|同构重复合并来源，行为重复退回；合法新生分配独立ID、权重和样本账。|
|证书与主链|登记未来起点、截止与ABI、观察机会、真实出手、校准、最差块、撤销原因；选择后写决策冻结|证书不再有效只影响下一次选择；保持已冻结/已结算原件不可改。|

## 创造并持续淘汰的实现细节

1. **快速历史训练**沿用原能力。将5000期热窗口做有跨度约束的走步回放。对期 t 先预测再在标签可用后更新；跨断口重置需要相邻期的状态。所有多位置派生数据按原始期分组，禁止以10个位置虚增10倍独立样本。旧档缺 knownAt 仅在允许的开发角色使用。
2. **候选的身份**由可执行 AST 或规范化模型、输入ABI、预测与更新规则、冻结出生信息共同决定。每次变化写父代、供体、操作、可执行策略和谱系。把 I00–I20、E01–E16、F01–F24、AtomNet 和矩阵分清思路、提案、模型和材料。仅产出新字符串或结构哈希时记录“提出”；经解析、去重且能用固定输入复演才记有效出生。
3. **多位置与短期结构**在历史冻结输入计算位置×号码的因果分数及集合支持，跨位置作交集或条件聚合后投影到固定单位置K3。真实交集不足按原策略HOLD。对照同时包含原交集、简单频次、去窗口、去矩阵、标签洗牌和延迟特征；给每个窗口预先定义期限、最小支持和变更版本。已知输赢后挑出的窗口只能提出下一轮假设。
4. **深度学习**按位置从同一训练事件得到模型预测；将前后权重摘要、样本数、损失、非零更新、优化器步、epoch及发布/消费ID串联。特征物化和残差积累分别计数。同一轮必须有十位置，缺位置只恢复缺失段。教师不可用时继续其他家族，F23只用真实绑定。以按时序留出的对数损失、Brier分数和K3命中同时核查数值与动作。
5. **进化、变异、融合**将替换子树、增删连接、改变图机制、加入/移除矩阵通道与纯阈值微调分列。以固定DEV窗口上的位置、K3集合、动作/HOLD、可用性组成行为签名，同构或同输出退回。双亲融合要求同目标、同角色和可解释互补，分别和父A、父B、移除一个组件重放；真正独立训练并留下差异才能记入子代改进。
6. **预算与退役**上限作用于当前活跃集合、每次CPU/内存/写锁/物理占用，终身出生计数持续累计。每轮为活跃槽执行“训练→评估→保留/退役→释放槽→再出生”。退役停止调度和晋级，保留政策hash、谱系、原冻结、失败摘要和证据来源；受保护祖先、证书所依赖原件按引用闭包保留。若不可释放，报告占用、根与清退条件。封存/压缩/迁移后需回读确认才释放旧物理占用。
7. **研究运营效果**记录候选从提出、可执行、去重、训练、行为新颖、配对胜出、未来登记、证书到实际主链的逐层分母和耗时。训练质量下降或新生停滞必须指出第一处阻点。研究调度按可用数据继续，候选不足时回到可执行的失败机制与新思路，不要求为了填满数目而出生。

## 统计与质量门

历史快速筛选采用DEV，参数及结构选择用SELECT，确认段锁定后禁止回流生成器。保留同一未来段作为正式资格账，序贯规则和多重尝试预算沿用仓库定义。样本不足显示分子、分母、时间跨度和区间；不得在确认集反复挑冠军。下列量在明确的同一策略、时间范围与角色中计算。

- 出手命中率 = 命中出手数 / 已结算有效出手数。频率 = 动作期数 / 合法机会期数。另报抓取覆盖和应有日历机会，防止漏期改善比率。无分母显示“未观察”。目标频率约15%起，保留用户希望在真实高质量时更频繁出手的目标。
- 开发集以每期的预测概率与开出结果计算 Brier 或 log loss。子父比较先固定同一目标期与损失函数，再按时间块估计配对差及区间。共同出手与动作并集各给分母，HOLD的效用须提前登记；不允许事后删掉劣势期。净差需扣已登记复杂度/时延成本。
- 多家族并行择优必须报尝试总数、有效去重数、队列和选择预算；在固定预算下对带信号合成序列与洗牌/无信号序列分别测检出和误报。合成或历史成功只证明机制和试验功效。自然代际改进需同目标独立证据。
- R27 资格分支沿用 `CertificateGateR27.evaluate` 的 `R27_GATE_V1`。版本一致、序贯已合格、未来有效出手≥250、命中率≥34%、ECE≤0.04、最差720块≥26%、最长连败≤6、语义ABI一致，且相对I00与洗牌对照的配对下界均>0。登记过期、撤销、时序和证据完整性还须在选择/冻结时核对。门过严的敏感性可另行预注册实验，沿用原门直到版本切换有真实依据。
- 自然达标才可走正式主链；`DecisionGateEngine`唯一授权一次REAL，`SettlementEngine`按冻结结算。活跃策略按当前权威选择函数排名。主页面分别展示新策略出生数、可训练数、活跃数、未来登记、有效证书、被选/被冻结/已结算真实次数。真实机会和实际出手是两种分母。

SU2 按已有 R26 协议独立签证。完整日历、四分段、配对和校准门及双候选选择顺序见 [两条资格协议](field-closure.md)。两类证书分别核验，最终正式授权和结算仍各有唯一入口。
