## 接口打包

`BinanceGameContract` 内置主 `https://api.duoqu.online/data` 和备 `https://api1.duoqu.online/data`，游戏代码 `Binance1-PK10`。首次安装不用手填地址；首页、凭据设置页及研究页均显示主/备完整地址。当前缺少服务要求的 API key，之前空key构建不能自动取数。本工作流读取 Actions secret `DUOQU_API_KEY` 注入，不公开密钥；凭据非空时 Android 还实际请求、解析并验证最新开奖。没有凭据时继续编译数值/Android测试，但最终可直接取数的安装包发布保持阻断。打包时的 `API_CONFIGURATION.txt` 明确是否内置凭据，不输出密钥值。

## 数值回执和验收边界

V8 五组完整历史执行结果保存在 `validation/phone-controls-v8/`，包含真实执行字节码base64归档、逐文件hash及结果。该快照在后续拟合图导入代码之前，绝不冒充最终APK同SHA实验。各组分配相同88候选，实际计算成本不同，没有证明稳定预测优势。

当前仍有22条PARTIAL，详见逐项清单。自然未来验证、实体手机持续热/内存/延迟验收、卸载或新包沙箱后的全球终身alpha保留均未声称完成。原始文件不以删掉验收项或把测试改成空实现来通过。权重、代码或来源改变都会使旧资格失效；历史结果不能升级为自然前瞻。

Android 实机 SQL 合同曾发现导入模型的参数截止与登记知识截止混用，导致 SU1_MODEL_PROTOCOL_MISMATCH。已修正：冻结权重 checkpoint 保留真实拟合截止；登记工件按本地登记时的保守知识边界绑定声明区间，区间明确 PENDING_NO_OBSERVATIONS_CREDITED，不授予任何验证次数或校准资格。本地历史未超过拟合截止时返回等待。回归同时发布并消费 RELGRAPH 和 RELSTATE 两类真实权重，数据库拒绝边界检查保持不变。
