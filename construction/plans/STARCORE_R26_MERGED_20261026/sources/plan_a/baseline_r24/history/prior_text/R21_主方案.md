本文件不是“把随机说成高胜率”，也不是“因为接近30%就宣布所有算法无效”。它保留原方案 P01—P50 全部功能要求，增加 P51—P68 的源码改造、研究方法、接口、数据契约和验收。原始 ZIP 在完整版包内逐字节保存。本轮新增的 Java/Python 核心已编译和实际运行；未完成的 Android 接线、完整旧引擎复原、手机测试，逐项列为待施工，不冒充已实现。

**本次实际状态：历史归档存在高胜率记录；本次新回放未达到35%且最长连挂不达标。因此不能发放“稳定高胜率已达成”证书。继续优化的对象是明确的模型表达、证据链、状态继承和部署环节，不是把低成绩隐藏、改名或删掉。**

原方案最重要的功能——原子/分子/矩阵、每期训练结算、结构发现、动态创造、变异融合、家族并行、失败诊断、排行榜、报告导出、后台连续运行——全部保留。取消的是不可验证的绝对承诺，不是功能。

## 三、统一目标与不可混淆的四种“通过”

**质量目标不降低：** 主检验命中率至少35%，37%为放量目标，40%为优先目标；最低覆盖15%，偏好30%以上；固定单位置K3，每期最多一条REAL；用户期望最长连挂不超过6，本方案以观测值≤6作为质量验收条件，同时提供≥6预警、≥7暂停建议。暂停不能保证未来连挂上界，也不能通过清零跨模型连续连挂美化成绩。

四层状态：`CODE_TESTED`（计算与状态契约通过）、`HISTORICAL_QUALITY_MET`（同预注册回放满足指标）、`FRESH_EVIDENCE_QUALIFIED`（新期证据通过、候选数量校正合格）、`ANDROID_REAL_VERIFIED`（手机唯一授权及真实冻结结算链通过）。任何一层不得替代另一层。

默认评价向量：命中率、全 eligible 期覆盖、有效样本量、时间一致下界/证据值、最差固定块表现、Brier/ECE、动作连挂、跨时间/状态退化、成本和延迟。K3命中率不是收益率；没有真实赔率/费用/投注记录时不输出盈利保证。

30%仅是“每一位置10个数字、选择固定3个且条件均匀无预测信息”假设下的比较基线。它不是给所有学习器预先指定的上限；公平比较必须看冻结后的同口径结果。

## 四、完整闭环：从抓取到真实证据，不加第二条实盘链

```text
FetchDraw → 校验/去重/记录来源与缺口 → SettlementEngine唯一结算事务
          ├─ 对上一期不可变预测精确标注 hit / skip / missing
          ├─ 插入幂等训练outbox（包括SHADOW和SKIP拟动作）
          └─ 提交后训练工作器：旧权重+冻结特征+本期标签 → 新模型blob
              → hash核验 → CAS发布model_head → outbox APPLIED
TargetIssueResolver → 输入截止期封印 → 当前已发布只读模型快照
          → 全部活跃策略预测 → 7/5/3集合推理/联合排列头
          → 校准/适用窗口/质量检查 → 冻结本期动作与原因
          → DecisionGateEngine唯一授权（本轮默认SHADOW，不解锁REAL）
后台研究：失败分桶 → 假设 → 有类型程序/深度结构搜索 → 历史切分训练
          → 候选登记/谱系封闭 → 公平影子调度 → 出生后配对验证
          → 通过才晋级，失败回到诊断；旧父代及其证据不覆盖
```

每期训练指所有“活跃可执行模型”学习一次本期标签，不是每个历史候选每分钟从头训练。模型实例按参数/状态身份去重共享；归档、排队和暂停候选必须分别计数，不能把它们的未执行算成成功训练。

## 五、算法创造能力：保留已有家族，再补齐关键层

### 5.1 真实历史优质种子库

种子记录必须含：原始源码/VM哈希、完整规范程序、状态blob、状态更新时间、score/update两个程序、原始号码面、冻结期号、预测哈希、结算结果及命中口径。不能只按46%标签把它当万能专家。

复现分三路：A精确旧执行器+原始冻结输入，B新执行器+同一输入的兼容性对照，C新数据出生后持续预测。A/B逐动作完全相同才称兼容；C另算证据。旧证据不足的种子仍可参与研究，但不冒充已经获得新证书。

### 5.2 因果多尺度结构表示

输入不只冷热遗漏：`X[time,position,number,channel]` 包含位置迁移、号码相对排序、跨位置条件关系、集合包含/排斥、相邻/对称位置、间隔分布、变化点、原子/分子响应、原策略的冻结概率面。窗口建议8/32/128/512；模型容量和窗口是实验参数，不是既定最佳值。

下一阶段实现因果扩张卷积或带严格因果mask的时序编码器，输入截止`t-1`，输出10×10分数。辅助任务包括下一期全排列、结构持续/转换、集合命中、模型不确定性。任何自监督表征、标准化、字典学习也只能在训练前缀拟合，不能对全历史预训练再声称后段未见。先比较低容量模型，再决定是否增加深层网络；网络更深不等于可预测信息更多。

本包已保留R20两个隐藏层的真实反向传播实现，并实际测试梯度与状态恢复；尚未把时序卷积/新编码器写成完成模块，列入P55施工。

### 5.3 精确全排列概率头：本轮已经写出并测试

对10×10 logits `L`，定义排列 `π` 的分布：

`q(π)=exp(Σ_p L[p,π(p)]) / Z(L)`。

`Z`是矩阵`exp(L)`的 permanent，不是 determinant。使用子集动态规划 `F[p,S]` 和后缀 `B[p,S]`，复杂度 O(n²2^n)，n=10可精确计算。输出 `M[p,n]=Pr(π(p)=n)`；每行、每列的和均为1。训练联合负对数似然的局部梯度是`M-oneHot(draw)`，限未触发数值截断的输入区域；生产实现需约束logits跨度或显式处理截断导数。

`PermutationHeadR21.java` 已实现分区函数与边际；测试用3阶全枚举核对、行列归一化、数值梯度及10阶均匀情形。它解决排列一致性，不凭空增加可学习信息。本轮附加回放表明仅加入这个头并未达到35%，所以不能靠“结构更高级”宣布成功。

### 5.4 多位置、多号码集合格：本轮已经写出并回放

每个位置形成多个模型视图，保留7码支持集合→缩5码→固定3码；每一步记录集合、贡献来源和冲突理由。`SetLatticeR21` 先按多视图支持建立候选，再在候选内按综合概率排序。交集不足直接`STRUCTURAL_CONFLICT`，不补号码凑K，不转K4，不改多位置REAL。

本轮结构组用 MSDIR、LOGLIN、RELBAYES、REGMEM、DEEPATOM 五家族；权重按每期揭晓后的全位置对数损失更新，不用本期标签先决定本期动作。整体预测研究可以是100号码面，最终真实动作仍只有一个位置三个号码。

### 5.5 有类型程序与符号发现

保留现有程序进化，增加类型：`Scalar`、`PositionNumberMatrix`、`NumberSet`、`PositionSet`、`LaggedRelation`、`StateMemory`、`Gate`。语法允许关系卷积、条件交叉、集合交/并/差、状态切换、稀疏残差、可学习聚合；禁止score访问label，update才可访问冻结label。

结构产生器根据失败原因选择操作：改信息来源、改滞后、加/删交互、替换状态更新、拆分相反区制、融合互补父代、蒸馏/嫁接。每次至少记录AST/拓扑差异、语义指纹差异和预先固定探针集行为差异。只改名字/随机种子/代数恒等表达式为`NO_OP`。数值变异是真正可用能力，但必须标`PARAMETER_MUTATION`，不冒充新算法家族。

神经引导符号回归是搜索表达式的方法，适配本项目时奖励必须包含外层前向稳定性和复杂度代价，而不只是训练拟合。相关研究只是方法依据，不是本数据必然高胜率的证明。

### 5.6 继承与融合：本轮补齐一段可执行能力

`DeepLineageR21.copy` 复制权重、优化器累积量、原子历史；`mutate` 在副本上作有界数值变异；`fuse` 仅在参数身份和完整因果历史一致时融合权重，优化器二阶量按逐元素最大值保守传输。父对象保持字节不变，子代证据N=0。

跨拓扑继承不能把同一个数组下标当成同一个语义。P58要求按特征ID/隐藏单元匹配/状态槽语义图映射；无法对齐则训练前缀蒸馏后重新验证。旧R908的跨程序状态不能盲目平均。保留冷启动子代作为对照，记录继承带来的训练效率与出生后质量，而不是预先认定继承更好。

### 5.7 真正大量创造，而非大量同质候选

建立质量—多样性网格：关系家族、滞后尺度、状态记忆、集合逻辑、校准/门控、预测行为。候选总数、独立语义数、有效结构变化数、进入活跃影子数、达质量数、通过新证据数分别展示。对相同预测序列聚类，重复公式不增加“资产数量”。

研究可以并行提出大量假设，但手机活跃执行受预算限制。名额分为在任者/父代对照、新家族、稳定精英、待验证挑战者；新增候选从排队转活跃时才冻结其未来评估协议。新家族有研究名额，不享有REAL通行证。

## 六、结果驱动的定向升级，不盲目重复同一历史

本次数值继承主检验31.41%，结构集合组32.50%，联合排列附加组31.78%，都低于目标；不能任选一个最高的改称预注册主检验。

诊断顺序应为：

1. 旧高分策略是否能精确重放；不能时先补原始冻结输入，不能用替代特征回放失败就否定旧策略。
2. 当前多家族中哪些结构真的在出生后带来增益；用全候选同口径报告，查筛选选择衰减。
3. 7→5→3每级留存真实号码的损失分解；只有“7码阶段好、缩到3码坏”才优先改缩减器。没有前级优势时优先改表示/状态识别。
4. 真实参数继承与冷启动同期对照；若只是继承同一种错误，需要换特征/状态/目标，不再只减小学习率。
5. 检验共同失败：相同原因/状态/位置/号码组下的失误是否相关；高度相关的父代不要简单平均。
6. 新结构研究先在训练/开发窗完成，再注册冻结实验，使用之后新到达的期验证；本轮已经反复使用的数据永远标记为探索数据。

所谓“一代比一代强”的实现语义是：**允许探索子代失败，但失败不晋级；已证实改进的晋级链才记为有效代。** 未来环境可能变化，仍需退役/回滚，不能用这句话保证永久单调命中率。

## 八、检验与晋级：不通过降低门槛凑“达标”

### 8.1 三层切分和暴露账本

训练窗决定权重；开发窗决定结构/阈值/家族；冻结后的新期验证决定是否晋级。每个实验记录datasetHash、issueRange、sourceCodeHash、参数、seed、家族、候选数量与数据曾被谁看过。重复用开发窗可以研究，但不能把它重新包装成独立验证。

用户的最低样本120只是开始审查条件，不代表120期足够证明稳定35%。样本有效性还受相关性、筛选次数、覆盖、期段和状态覆盖影响。四固定时间块不允许看到结果后重划。

### 8.2 顺序证据

对可预测地选择的动作、条件命中率不超过p0的原假设，有限替代概率混合的似然比为：

`E_t=mean_q product_{i<=t}(q/p0)^hit_i ((1-q)/(1-p0))^(1-hit_i)`。

`EvidenceGateR21` 使用对数累积避免溢出。全局第j个登记检验分配 `alpha_j=0.05*6/(π²*j²)`；跨进程、跨重装、跨策略不能重置j。新实例/政策/阈值算新试验。只有新到达的合格冻结标签进入认证流；本轮历史回放统一 `freshEvidence=false`，所以不能授权REAL。

`p0=.30` 的证据只支持超越30%基线，不证明长期下界≥35%；后者必须另设`p0=.35`的检验/置信序列。描述性Wilson区间不能作为反复选赢家后的有效保证。

### 8.3 父子比较和有效代

同一目标期比较父子，完整保留双方SKIP和系统漏期。命中率比较同时报告覆盖；不同出手集合不可只比命中数。提供同出手期差值、全eligible期 `(act*(hit-.30))` 的基线调整表现及覆盖差；该得分不是实际利润。每个孩子建立独立登记的父子试验，存在多个父代要明确主比较对象。

`proposedGeneration` 每次提出+1；`trainedGeneration` 完成训练+1；`structuralGeneration` 经类型/语义检查+1；`verifiedGeneration` 只在新证据和父子增益通过时+1。实测失败或NO_OP不计verifiedGeneration。

## 九、资源、后台运行和存储

实时优先级：抓取/结算→赛前读取与冻结→轻量在线更新→研究。主机本轮耗时不外推到手机。手机总闭环目标≤5秒，其中推理/冻结建议预算≤1.5秒，训练以50—100ms可抢占切片运行；具体值必须通过实际设备矩阵测定。

每个target保存完整终态：FROZEN_ACT / FROZEN_SKIP / DATA_GAP / MODEL_NOT_READY / BUDGET_EXPIRED / SOURCE_CONFLICT。预算过期不使用结果晚到后回填为赛前预测。影子覆盖率以全部eligible期为分母，系统漏期与策略主动SKIP分开。

在线原始历史严格最多5,000期。长期保留必要累计统计、alpha消费、出生工件、晋级证书、故障证据与内容寻址hash；有体积预算时做有界档案导出而非无条件无限保存。离线测试夹具可含10,000期，不代表手机数据库上限改成10,000。

训练模型与推理模型双缓冲；发布新头使用CAS且带学习截止期。不得把深度反向传播塞进SQLite长事务。大模型blob先落盘校验，DB仅原子更新指针和outbox状态。文件清理必须遵守仍被证书/未结算预测引用的引用计数。

## 十三、补充：本轮继续优化后新增的联合训练与预算修正

### 13.1 不是只给旧网络套排列后处理

集合结构回放32.50%，加入后处理排列头31.78%，因此追加一个明确的机制实验：让深度网络直接学习全排列联合似然。`DeepPermutationNetR21.java` 保留两隐层和真实RMSProp，将输出约束为 `20*tanh(z/20)`，用精确排列分区函数计算联合负对数似然，反传边际减观测指示量，再乘有界输出导数。它不是把独立softmax概率事后重新命名为联合模型。

332个参数坐标的数值梯度核验通过，最大绝对误差约3.52e-9；恢复后逐期预测一致。五家族结构组替换深度成员后，回放为184/563=32.68%，覆盖28.22%，最长连挂15，仍未达35%和连挂目标。该附加实验不替代预先指定的R21主检验；比32.50%高0.18个百分点不构成有效改进证据。

本轮已交付的新Java核心共7个，其中`DeepPermutationNetR21`属于新增联合学习器。P55中更长时序编码器仍是待施工项，不能混称已实现。

### 13.2 冻结学习规则，不是禁止每期更新权重

资产身份应绑定学习规则、初始化工件、特征定义、更新顺序、门控政策和随机源；同一已登记在线学习器按预定规则更新权重时，不应每期重置N。每期预测另绑定具体stateHash和historyCut。改变结构/更新规则/选择政策才创建新资产并重新登记未来评估。否则“每期训练”和“永远样本不足”会被错误地写成死循环。

### 13.3 研究尝试预算与正式认证α必须分账

在训练/开发窗内部生成大量程序，应完整登记搜索尝试和计算费用，但不必把从未查看正式验证流的每个训练候选都当成一次正式认证检验。先冻结有限的待验证候选/自适应选择政策，再为真正访问新验证标签的检验分配全局α；曾经看过验证标签的失败试验不得删除或返还预算。

建议每个验证周期最多登记8个独立挑战政策，其他研究候选在开发流继续搜索。数字8是工程初始预算，要在开发数据上评估，不是最佳数量保证。这样保留“大量创造”的研究能力，又避免给数百万训练候选逐个分极小α导致实际上无法认证。`ResearchMultiplicityR932` 既有paid attempt不能删除；新增confirmatoryTrialId和exposureRole分离两种消耗。

### 13.4 不能承诺每个候选都逐期深度训练

“每期全量”的可执行定义是当前活跃集完整覆盖。已归档、排队、只做历史预筛的候选不是活跃集。手机预算不足时减少新候选入场速度并保持父代/在任者的连续证据，而不是先把活跃集无限扩大，再以预算不足漏期。

### 13.5 时点接口转换

Java回放使用零基索引t，`trainedThroughExclusive=t`表示只使用0..t-1；SQLite参考ledger使用目标ordinal和最后已知ordinal，`history_cut<issue`。Android适配必须显式转换，不可把exclusive=t直接写成history_cut=t。期号比较不得跨游戏或跨来源直接按字符串拼接。
