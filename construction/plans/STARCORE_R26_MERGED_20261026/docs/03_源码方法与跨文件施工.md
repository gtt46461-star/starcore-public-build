## 必须实现的接口

```java
interface WorkUnitR26 {
  TaskKey key();
  SliceResult step(ImmutableSnapshot input, DurableCursor cursor,
                   BudgetToken budget, CancellationToken cancel);
}
// 返回的是已计算但未发布的结果；persistAndCommit由原数据库Owner完成。
// SliceResult含phase/candidate/sample/optimizer/RNG/consumedEventIds/stateDelta。
// cancel检查在最内层；未提交状态不能伪报进度。
```

RuntimeCoordinator只编排，不获得REAL授权。任务队列的SQLite表放原数据库，写入继续走原DatabaseCoordinator。一个服务会话持有租约token；lease更新先在工作线程持久化成功后生效，不简单把主线程commit改apply来牺牲恢复一致性。

## 上线顺序与删除前置

先引入持久队列和可回放切片→在隔离环境验证原Job职责迁移全覆盖→服务成为唯一驱动→取消原JOB_ID→删除原Job重复工作调用→全仓调用扫描查无旁路。过渡期可以保留类名兼容旧manifest，但不得同时存在两套实际训练Owner。旧任务迁移失败则回滚激活开关与已验版本；不能让旧充电模式成为最终交付行为。
