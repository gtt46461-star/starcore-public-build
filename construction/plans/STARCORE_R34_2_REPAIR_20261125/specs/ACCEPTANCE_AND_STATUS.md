# 验收分层与完成口径

## 可独立签收的六层证据

1. **计划完整性**：问题、原因等级、文件、方法、所有者、数据合同、批次、测试、恢复路径、证据引用均存在且可解析；依赖无环。此层不证明应用已修复。
2. **源码实现**：目标方法发生实质变更；真实调用者接入；迁移顺序可执行；差异有before/after及commit。
3. **合同和集成**：同一个生产入口经过确定输入、故障注入、重复、边界、恢复、并发和反例验证。仅mock显示某个函数被调用不足以验收数值训练或创新。
4. **构建和安装**：完整APK、源码、资源、manifest、版本、签名和hash相互一致；同包同签名覆盖安装并启动。签名私钥不进公有仓库。
5. **设备持续运行**：用户设备/同型目标设备执行前台、后台、息屏、切换网络、系统杀进程、升级恢复及24/72小时窗口；每个机会的事实和缺失可对账。
6. **自然质量**：事前登记、未被训练或挑选污染的未来样本证明命中、稳定性、校准、频率和代际相对改进；时间未走完就保持PENDING，不由合成试验代签。

## 每批最小回执

`batch_id / issue_ids / source_before / source_after / changed_files / exact_test_commands / exit_codes / evidence_hashes / apk_identity / rollback / remaining_device_or_natural_conditions`。

完成本批代码与合同回归即可签本批工程合同；不能因为B12以后还会测试，就把本批缺失的迁移、调用或输入留给B12。对必须等待真实时间的外部验收，工程完成和外部未完成分别列示。任何层缺失都不写“全方案100%实现”。

## 必测反例

- fault backlog跨越保护阈值，排空遇到中断/损坏/容量不足后可继续；没有删故障原件。
- 同一DEPENDENCY连续三次，依赖恢复后原owner能重新启动；真正BUG仍有冷却和隔离，不热循环。
- 部分分子目录未完成时，无该依赖的基础家族能够训练；依赖它的家族不得偷用未验证目录。
- 基础枚举耗尽后仍能形成结构新候选；参数微调、改名、无效父边、交换律等价树不得计为新机制。
- 新规则被两个未使用开发区间消费并形成两棵去参数不同的可执行结构，关掉新规则的对照消失或结果不同；重启后规则恢复可用。
- 一次融合必须有双方有效执行贡献；消除任一父方后的对照、结构/行为多样性和配对质量一起记录。
- 历史快训只影响DEVELOPMENT产物；未来窗口不增加；重启后从精确模型状态和游标续训。
- 同一期多位置/多策略预测不能扩大独立开奖分母；模型变化不能继承旧冻结实验的评价与证书。
- 数值更新必须有输入hash、旧模型hash、参数变化/梯度或训练器证据、新产物hash、消费回执；状态行增加不能代替这些证据。
- 新合格模型经真实生产选择器与DecisionGate被使用；失效/过期/不兼容证书必拒绝；不存在永久全局零权重，也不存在无证书REAL旁路。
- 当前请求成功但其他应有期缺失时，覆盖和SLO不能显示总体PASS；小样本P95同时显示样本量和未测数。
- 报告对缺表、跨进程、跨快照、不完整原件给出UNKNOWN/EXCLUDED及可执行采集项；不制造0，不沿用过期fault因果断言。

## 性能验证规则

只比较同一安装版本、同一角色和足量同口径窗口。分别记录网络wake、有效响应、数据入库、请求、输入捕获、推理、等待写锁、commit返回、结算、投递和消费者提交时间。端到端超时由这些分段定位。

本报告当前安装作用域仅1个有效时延样本，2804ms不能证明长期达标；累计198个样本P95=10616ms又不是当前版本独立P95。两者均保留，不能任取一方替代另一方。改进后先用固定可重复负载对比，再用自然机会窗口验收；慢样本、缺失样本和退避都不得剔除后只报成功。

## 统计质量规则

固定K3、一个位置10个号码的均匀无信息命中基线为30%，前提是对应开奖无可利用的条件偏差。报告累计SHADOW为594/1858=31.96986%，95% Wilson下界约29.88838%；该数据不能单独证明超过30%的稳定优势，更不能替新策略族或新模型版本的独立未来证据。

不存在跨所有路径通用的“120期即可发证”。152源码的 `CertificateGateR27` / `R27_GATE_V1` 要求至少250个已结算FUTURE ACT、命中率≥34%、ECE≤0.04、最差720块命中率≥26%、最长连败≤6、语义ABI等价、序贯检验通过并且胜过两个同池对照；这些完整原门槛必须保留。SU1、SU2和CP4精确冻结域有各自的原始冻结协议、角色、预算及消费者验权，不能把R27的250或旧展示的120强套到其它域，也不能择最低门槛放行。

四类证书的实际分派、完整合同索引和最终门接线见 `CERTIFICATE_DOMAINS.md`。所有路径使用各自当前冻结质量合同、序贯/多重比较预算、同目标配对、跨块稳定性和概率校准；输出明确的证书域与policy_hash。失败的策略保留反证并退出活跃预算；父代冠军在子代未经验证前继续保留。允许探索失败；只把验证后更好的结果晋升为新冠军，不承诺每个子代更强。

## Android与SQLite边界

本次设备为Android14；不能用Android15的dataSync六小时限制解释当前现场故障。若未来提升target或系统，必须按平台版本单列后台服务限制和超时测试。WorkManager周期任务最小间隔15分钟，不能取代1秒实时轮询。现有前台服务和轻量恢复所有者继续保留。

删除SQLite行通常只产生可复用空页，不代表文件立即缩小；WAL checkpoint也不等于数据库VACUUM。保留原件/备份/报告snapshot需有引用闭包及释放回执；需要紧缩时在独立维护窗口、空间预检、可恢复备份后进行，不在实时事务或页面线程执行。
