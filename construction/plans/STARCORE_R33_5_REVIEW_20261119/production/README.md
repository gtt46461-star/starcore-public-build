| sources/B02/ | 结算写入、反馈读取、耐久时点、启用日记取证。七份Java和Android清单。 |

| OVERLAY.json | 相对原方案及旧B05修订的逐批补正；每条核原有效后态、真实前态和当前完整后态。 |
| before/、images/ | 安装器消费的完整前后字节，包括跨批R82、语义依赖及原R967两项已跟踪输出。 |

相对于原卷新增22次操作，分别为14次R967已跟踪生成文件入账、B07的5次操作，以及本次B02新补列的3次操作（结算标签写入器、启用日记provider、Android清单）。B07七份Java中两份原清单已在B07登记，改为新后态；另外五份新增B07操作，其中三份为全新Java类。生成文件此前已存在于工程，补列其路径控制，使不同路径总数从129变138。

生成器采用原`build_semantic_inputs_r335.py`和原`r967_semantic_identity.py`。原policy不变、原validator不变、不降低已有数值角色，旧资格兼容列表为空。`CapabilityNeedDiagnosticsR335`的反射仅查有限白名单的精确方法声明，不初始化、不调用方法；其全文与动态依赖审阅均受哈希绑定。新的报告类按保守数值角色纳入身份，不从“报告展示”推导资格兼容。

有效完整清单由`replay/production_overlay.py`临时组合并通过原`validate_install_manifest`验证，供安装、所有前缀编译和完成源终验共同使用。原认证卷不被改写；本目录的补正不是孤立贴片，已经进入实际批次安装链。
