# R335-RE21 启用日志的 Android 持久化读回

正式 APK 的设置入口在新装模拟器上点击启动两次，七次 shell 读取均返回 R335_ASSIGNMENT_UNREADABLE。应用内具名测试在同一签名 APK 上证实当前布尔值为真，原哈希日志已记录，内存回放成功，而从 Android 真实持久化 XML 读回时报 JOURNAL_TRUNCATED。另一台新装模拟器以两个框架解析器分别测得内存日志 779 个字符、4 个 LF，两个落盘解析均为 783 个字符、4 个 LF。

Android 在以 LF 结尾的 string 内容与结束标签之间缩进四个空格。正式采集入口与进程重启后追加事件的入口均还原这一确切的序列化后缀。应用仍检查原链每个事件、时钟、源码、首尾摘要、启用布尔值与保存状态。缺少原 LF、其他后缀、算术异常及篡改摘要继续拒绝。先前缺失的机会保留 UNKNOWN。原方案、两份完整前后态、受控负例以及修正前后的实测收据按文件保存。
