# 质量、覆盖、稳定性与代际验证协议

## 1. 三种数据用途不可混同

旧记录复现：原程序、原参数/状态、原输入截止与逐期冻结一一复核；失败定位至执行器差异、输入差异、保存状态缺失或汇总错误。不得因新模型失败就否定旧记录，也不得仅凭旧70/152汇总证明所有后续版本有效。

历史研究：可以反复训练、变异、蒸馏和消融。每次记录exposure ledger；开发者看过的数据即暴露，不因为重新切70/15/15又变回未见数据。

新期验证：候选结构、学习规则、选择规则及允许的在线更新预先登记，然后逐期冻结。符合登记的在线参数更新可属于同一政策；改变结构、规则、数据可见范围或选择器则新建政策版本。父代资格不能直接转给子代。

## 2. 质量门的独立组成

EngineeringReady、PredictionIntegrity、SampleMaturity、QualityCoverage、HitQuality、Stability、Calibration、NovelEvidence、MainlineHealth分别输出。一个布尔值不能把缺样本、预测缺席、统计退化混为一谈。

默认产品检查维持：长窗约4000期、约600次动作对应15%；动作命中目标≥35%；更强37%/40%；观察最长动作连挂≤6；校准和分块指标通过预注册阈值。现有证书若另有严格要求，必须在冲突表中对齐，不能默默放宽。600次动作不是“足够证明任何目标”的万能样本数，特别在多次搜索/相关条件下需看实际检验。

近期1500期225次动作不应仅因少于250而降级；近期信息不足为INFORMATION_LOW，数据缺口为OBSERVATION_GAP，真正退化按其检验或风险事件处理。

观察到连续7次失利可暂停授权，但暂停本身不能改善已发生连挂指标。后续恢复遇到继续失利时接着计算。合格策略在未来仍可能退化，不能承诺永久不下降。

## 3. 多次查看、多个候选的证据预算

主机evidence_r23.py提供预先固定lambda混合的Bernoulli e-process：

    E_t = mean_j product_s [1 + lambda_j (hit_s - p0)]
    alpha_j = alpha_total / (j*(j+1))

其解释前提是被选动作在零假设下满足条件期望E[hit_t|过去]≤p0，lambda及候选注册不可事后按未来结果选择。它检验条件均值优势，不证明未来某固定命中率，也不是自动的35%下界。与单纯独立同分布假定不同，但仍有明确条件。代码测试只核对有限反例/数学实现，不能单独给现实数据授予证书。[M9]

p0=0.30仅对应单位置均匀、无条件可预测优势的参照，不是预先断言实际过程必定如此。若要声称已支持≥35%的平均质量，必须针对相应目标另设可审计下界/检验；不能把拒绝30%写成证明35%。

候选注册号和alpha支出持久化不可重启清零，失败候选也占用预算。大量研究候选先在DEV筛选，只让有限个预注册挑战者进入新期验证，避免无限多模型消耗同一份证据。进一步采用时间一致区间需要验证其估计对象、漂移条件和覆盖性质，不能只换名称。

## 4. 父子真正同条件比较

父子在同一未来区间同时影子冻结，使用同一历史可见截止、动作成本、故障分母。分别报告：共同动作期、只有父代动作期、只有子代动作期、共同不动作期；每机会命中、动作命中率、覆盖、校准、最长连挂、资源。不能只比较两条不同动作子样本的独立比例z分数。

预注册目标在约15%覆盖下比较命中质量与稳定性，配对/成组重采样或顺序检验必须考虑时间依赖。策略选择器本身是测试对象。依赖稳态假设的block bootstrap只作为在该假设下的区间，不冒称任意漂移都有效。

verifiedImprovementReceipt至少含父子政策hash、出生期、共同区间、两条冻结流hash、比较协议hash、行为改变证明、工程通过、质量通过、新期证据通过与比较结论。只有所有必须门满足才增加verifiedImprovementCount；统计未明确时保留当前在任资产，不伪造必然改进。

## 5. 15%前沿不是机械分位数

生产选择模型先校准其被选动作的概率。候选门阈值只在TUNE或过去独立校准流上决定；评估同一冻结政策的质量/覆盖，不能用评价区间反复调门到刚好达标。报告全区间及固定块的前沿，没有合格点就报告不可行缺口。

更多频率并不是上限禁令；只要更多机会满足相同质量与证据要求就可以动作。频率不足不能用不合格动作补数。每个稀有专家可研究，最终主链唯一动作流必须独立达标。

## 6. 不得事后挑出“成功模拟”

R23指定主路线33.2636%未达标，保留所有单模型失败结果。局部块42.86%不代替总体；也不能反复换种子直到找到35%后删去失败。后续发现的好方案进入新登记的验证，不把持续优化历史反复包装为新的证明。
