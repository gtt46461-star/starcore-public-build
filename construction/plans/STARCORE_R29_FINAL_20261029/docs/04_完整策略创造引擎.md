# 完整策略、思路族与失败驱动进化


## 1. 每个资产必须是一份完整可运行决策

新增PolicyContractR29：hypothesis（业务假设）、domain、PIT feature set、score/probability、position selector、K3 rule、ACT rule、online update、calibration、failure conditions、complexity budget、parents、semantic delta、train lineage。缺任一核心可执行部件就拒绝，不能随机拼一个数学式后起个名字。typed AST保留，增加编译期单位检查、常数折叠、等价消除、NaN/缺失传播、行为指纹；数学正确不等于预测有效。

生成路径：假设提案→数据支持统计→类型图生成→模型/参数拟合→成本与PIT校验→分层回放淘汰→多样性档案→一次确认→冻结观察→资格→主链→结算反馈。原有512活动种群和连续减半可以复用；计算吞吐、结构新颖、行为新颖、研究存活、自然达标分别计数。

## 3. 多位置多号码交叉交集与短期结构窗口

这是研究路线而非预设赢家。为每位置p、尺度w计算事前号码分布P(n|p,w,history<t)。从多个模型与位置关系生成覆盖集合S(p,w)，集合大小可为4—7（仅研究中间态），记录真实覆盖与支持数。对候选号码的多路支持使用可靠度/相关性折扣，不把同源模型重复投票当独立证据。逐层缩减到K3，并记录从集合覆盖到K3命中的损失；最终位置选择器只能使用事前特征。

新增WindowProposal：结构描述、开始检测时间、特征阈值、预计有效期、支持数、基线、退出条件。结构包括集中/分散、位间迁移、冷热切换、重复/轮换、相似片段等可计算关系；不宣称准确无误预知走势。阈值在SELECT固定，随后确认window_detector+set_builder+shrink+selector整条链。真实时段跑原始大集合、逐层集合和K3影子，可判断是窗口错、围号漏、缩减错还是选位错。

## 4. 失败驱动的结构进化

失败树至少包括NUMBER、RANK、THIRD、WINDOW、REGIME、MOTIF、RELATION、CONSENSUS、CALIBRATION及ENGINEERING/PIT故障。每条ResearchFinding含evidence rows、支持/反证、关联而非因果标识、拟修改节点、父代hash、预测改进指标、禁止变化的约束。

具体算子：替换概率核、增加带支持门的条件分支、窗口尺度重组、检索距离变化、跨位图边剪枝、分子插入/移除、低相关模型融合、校准器更新、在线遗忘规则变化。变异后独立hash与新证据起点。真实失败可指导搜索，但不直接宣称“原因已证明”。至少比较父代、结构修复子代、参数微调子代、等预算随机搜索子代；同一期配对考察修复到底有效没有。

研究资源首版建议：60%成熟有支持家族、20%故障修复、20%新假设；各族至少有一个可恢复实验队列，长时间无进展必须给原因。配额是可调工程参数，预算变化本身不能消耗确认结果来调优。选拔采用多目标档案：SELECT机会优势、校准、复杂度、频率、跨块稳定、行为距离；确认结果只决定是否替换，不回流同一确认块继续搜索。
