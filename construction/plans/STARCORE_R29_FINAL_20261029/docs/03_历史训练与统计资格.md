# 历史训练、时间隔离与自然资格


## 1. 历史训练必须保留并升级

继续利用已有真实开奖快速筛垃圾、修策略、做消融。ReplayDataset支持连续段、去重、脏数据、来源/firstSeen和导入manifest。实时热库滚动5000期；研究历史需要更长时使用单独不可变压缩回放块并设置总量上限、数据集hash和pin。历史导入不改变firstSeen，不能反写为当时已知。

时间顺序划分 `TRAIN → SELECT → CONFIRM → FUTURE`。TRAIN拟合参数；SELECT选择结构、超参和阈值；CONFIRM为冻结候选包的一次确认；FUTURE从注册后的真实冻结开始。同一期所有位置、派生窗口与模型样本必须处于同一时间角色。历史特征窗口可以读取更早历史，但标签/参数/归一化状态绝不可读取评估时尚未可见的未来。边界重叠标签需purge；不采用打乱K折。

R27 `HoldoutLedger.MAX_DISTINCT_LOOKS=64` 不是防过拟合证明。`AtomScore`、早停、复杂度调整、停止条件、专家提案、报告反馈只要消费某块结果，就登记读取目的；参与新候选生成的块自动降级SELECT。不能再称未见测试。自然未来一旦用于父代诊断，可以训练子代，但子代从新时间起点积累证据，不能继承父代未来分数。

## 2. 完整策略身份

策略hash绑定：typed AST/模型拓扑、特征ABI、模型初始state hash、输入预处理、位置选择器、K3输出、ACT规则、校准器、在线更新规则、训练截止、缺失处理、复杂度/资源预算。只改名称不算新策略；参数调整与结构变异分开计数。确定性在线学习规则在事前冻结时可以作为一个序列策略受评估，每期权重版本与trainedThrough必须留证；事后修改更新逻辑则新生。

## 3. 统计口径

对策略j：N_sched=注册后全部应有期；N_frozen=截止前有效冻结期；N_act=该策略事前ACT且可结算期；N_hit=对应命中。HR=N_hit/N_act，coverage=N_frozen/N_sched，actRate=N_act/N_sched；同时列缺抓、迟到、待结算，不用已结算数缩小机会分母。同一期100号码格或1200动作仅是条件候选，不能放大独立样本数。

固定单位置K3在均匀独立假设下基线为0.30，这是检验基准而非“已经证明数据独立”。若净中收益W、不中损失L，保本概率为L/(W+L)，赔率/费用必须从当前配置读取并校验；+6.9/−3仅是旧方案算例，保本为0.3030303。没有有效赔率时不出收益达标结论。

描述展示用Wilson区间并明确固定样本性质。重复看结果、择优挑策略时，确认采用预登记永久alpha分配和可预测下注系数的e过程。每个策略在首次资格注册时领取永久globalIndex；延续相同语义和已注册更新规则时续接，不因换版本号/退出再入重置。历史观察中挑中的赢家，从注册后新数据开始，不回填旧观察分数到新e过程。

R29建议检验基准p0=max(0.30,已确认保本概率)，`u_t=ACT_t*(hit_t-p0)`；`E_t=E_(t-1)*(1+lambda_t*u_t)`，lambda仅来自t−1以前且约束使因子非负。统计有效性前提为零假设下条件均值非正、可预测ACT/模型/系数、真实冻结及幂等顺序结算；不能对任意非平稳数据无条件宣称终身5%。沿用现有永久alpha规则时需要校验归一化上界、断电恢复和全局序号唯一性；不可把e-BH的FDR说成FWER。

## 4. 资格通道与不浪费样本

发现池目标128真实候选+16负对照；不足不复制凑数。确认池16个名额（作为首版资源参数），历史SELECT/一次CONFIRM选入，按家族与行为聚类去重。确认前冻结选择理由、队列、样本计划、停止条件。确认池不因新一代排名变化被挤掉；安全错误、预登记无效停止条件或完成确认才退出，账本永久保留。发现池榜单不能自动发证。

准入需HR≥34%、N_act≥250、有效e证据、语义/PIT/覆盖通过、校准可靠、跨时间区块稳定和主链组合验证。250只是最低记录数，不是足够证据承诺。对父子比较用相同期号的机会收益差；按期号/连续块重采样或有效序贯配对方法处理相关性，不使用独立两样本Z检验冒充配对结论。所有质量结果列出效应量、区间、样本数和未满足原因。

## 5. 准入可行性修复（不可静默放宽）

当前CertificateGate要求最长连挂≤6。本包精确递推显示，独立命中率34%、250次出手时此项通过率约0.00470025；40%时也可能经常失败。这只是规则可行性算例，不能代表设备策略表现。保持旧规则和旧证书语义不变；新增 `R29_GATE_V2` 实验配置，把连挂作为风险监测项，用事前确定窗口内的预测分布尾部概率及收益回撤报告替代“任意时长永远≤6”。启用新规则必须通过负对照误授证、注入优势检出力、漂移退出测试，并把变更写进发布报告。

同时维持HR≥34%、有效优势证据、校准、覆盖及唯一REAL责任，不靠连挂门修改制造命中率。未完成上述规则验证时，旧主链保持原有资格门，不得绕过。目标15%是研究优化目标；不能为了补足出手次数强制ACT。若有效策略仅覆盖10%，明确未达到频率目标并研究互补窗口；若质量支持更高频率，不人为限15%。

## 6. 首版固定配置与调整纪律

具体默认值统一于 `registries/r29_policy_defaults.json`：确认池16、发现候选128+16对照；稳定性采用事前固定的3个完整720期区块，每块至少80次ACT且最低块HR≥26%；校准验证至少200次ACT，固定10个等宽概率分箱；ECE由全部验证样本按箱样本比例加权，空箱权重为0，不强制填满5箱。已占用箱中样本≥20的箱需覆盖至少90%的验证样本；稀疏箱仍计入ECE并单列不确定性。ECE目标≤0.04，只说明实际支持概率区间的验证表现；区间、支持范围及漂移必须并报。样本支持不足必须等待或报告未达标，不合并事后好看的区块。连挂风险尾部阈值0.01仅用于事前固定窗口检查，反复监测须有效序贯方法。

这些数值是明确可施工的初始规则，需在完整负对照和优势检出力实验中检查可行性；不足时输出功效报告并另立新policy版本，不追溯修改旧实验或把工程参数调优当预测效果。所有门通过仍不保证未来收益。

## 7. 避免资格流程互相等待

校准拟合使用TRAIN/SELECT的合法时序预测，冻结校准器hash后再注册完整策略的未来确认。不能等“已授证ACTIVE”才允许拟合，又把拟合成功作为进入ACTIVE的前提。若确认过程中重新拟合校准器，新版完整策略从新起点验证，旧版证据保留但不拼接。资格前评估FUTURE ACT机会频率，主链部署后另评Q02真实频率；不得要求零REAL的新候选先具有15%真实出手才能授证。目标未达到仍如实报告，不强迫出手。

资格状态只按连续期号推进。迟到开奖与缺失期的恢复合同见docs/12；迟到的**开奖结果**可以结算已经合法冻结的预测，迟到的**预测**绝不补造FUTURE。
