# AtomNet、原子分子、20类矩阵与校准


## 1. 现有接线的精确修改

`AtomReplayR27.build`当前按ordinal轮换一个位置、用历史频率top3构造action；`AtomWorldR27.samples`每期加一条样本。改为按期号批处理10位置，输入显式含position、action/候选定义、缺失mask和历史截止；输出 `[10][10]` 位置号码分布及可选K3命中辅助头。号码损失采用真实号码交叉熵；K3辅助头采用同一事前K3的二元损失。不能把轮换单位置K3二元模型直接当任意位置100格号码模型。

`IdeaI08NeuralRepresentationR27.generate`当前仅建family叶子。新增 `model_surface(modelId, checkpointHash, position)` 叶子及FeatureCache接口，显式绑定trainedThrough、featureABI、时间角色和缺失原因。回放评分必须使用该历史时点以前训练的模型/确定性重放状态，不能用已训练至今天的网络回测过去并称OOS。改变checkpoint或更新规则按PolicyContract登记。

新增ModelArtifactR29保存网络权重、Adam一/二阶矩、step、学习率计划、RNG、标准化器、回放buffer游标、训练截止、输入schema、模型形状、归一化与checksum。恢复测试要求同一下一条输入的预测和更新在容差内一致；只保存权重不算可续训。`atomNetStep`不得在数据hash变化时无条件新建模型且清零在线步数；明确继续训练、窗口重建与语义重生的区别。

## 2. 样本和训练调度

前480/2048期等不同特征warmup按算子声明，缺失mask不能统一当0。5000期×10位置是至多50000行训练输入，TRAIN角色实际行数还要扣warmup、缺口、SELECT/CONFIRM；报告同时列rawRows、usableRows、uniqueIssues、effective support。禁止借十位置、重复epoch或合成扰动冒充新增独立开奖。

初训按批次64行、最多20 epoch、SELECT早停patience3复用现有设计，变成可恢复切片；每期先冻结新预测再消费相应标签，继而训练并产生下一版本。在线经验回放保留近期样本及历史分层reservoir，持续学习回执必须覆盖每个结果事件；学习率/剪裁/正则化只在TRAIN/SELECT调。NumberQ/Ranker接入相同的时间分组数据和artifact协议；先用小MLP、FTRL及现有家族核做对照，只有轻量时序模型验证有效后再扩深度，不默认上GPU集群或Transformer。

无真实保留集改善则不发布新模型；新模型冻结后上影子。BSS、logloss、ECE必须比较相同目标、相同期号、同一ACT条件；网络号码面与K3命中概率不得混算同一Brier。梯度/SHAP类贡献只是模型敏感性解释，真正有效贡献需要消融与后续独立验证。

## 3. 原子和分子

保留240原子定义及可评分条件，保留已有170评分行和394幸存分子，不以数量达标代替效果。每原子登记输入域、最大历史依赖、PIT语义、缺失/异常率、计算成本、消费者、TRAIN/SELECT/CONFIRM/FUTURE贡献。当前AtomScore按HOLDOUT分数决定状态时，该结果如果进入leafWeight就已参与选择；必须转成SELECT或分开确认。

单原子评分应在同一期与基准/去除该原子的模型进行配对；打乱标签用于整套搜索管线负对照和过拟合诊断，不能把一个随机打乱样本的差值当成严格可交换的因果对照。仅当前区间跨0标 `NO_ESTABLISHED_GAIN`，不是“证明无效”。有害判定需统一效应方向、置信区间、多重比较控制及样本支持。多个相关原子成组消融；分子以typed子图、子节点hash、训练来源、成本和行为差异登记，不因换常数虚增分子种类。

## 4. 20类矩阵的最低生产—消费合同

矩阵必须有真实producer、consumer、asOfIssue、tensor dimensions、inputHash、modelHash、rows/support、validity；缺数据记录MISSING，不写全零当成功。每期只增量更新必要状态，完整诊断快照低频物化。

|编号|矩阵|生产输入/输出|消费与验证|
|---|---|---|---|
|M01|Transition|历史相邻期号码条件计数|I03；行归一化/稀疏回退|
|M02|ConditionalTransition|跨位/体制条件转移|I03/I04；仅历史条件|
|M03|CoOccurrence|历史跨位置联合约束|I04/I15；不得用未开奖同期数据|
|M04|Frequency|多窗口位置号码频率|I01/AtomNet；每位置归一化|
|M05|Omission|遗漏与生存风险|I02；截尾与支持数|
|M06|AtomTarget|原子对目标损失差|生成器/消融；按期聚类|
|M07|AtomRegime|原子在事前体制下表现|I06/权重；防事后分组|
|M08|CandidateWindow|策略×窗口表现|I18/选择器；确认段隔离|
|M09|CandidateError|冻结预测残差|失败研究；绑定freezeId|
|M10|CandidateSimilarity|K3/ACT行为相关|去重/融合；不能等同源码hash|
|M11|CandidateDiversity|族×结构×频率格覆盖|档案/生成预算|
|M12|ParentChild|父子结构差与配对结果|进化替换/谱系图|
|M13|Drift|输入/残差分布变化|研究优先级/降级；基线窗口固定|
|M14|Residual|模型误差分群|I17修复；附反证|
|M15|Confidence|分层可靠性/校准分箱|ACT门/报告；不回看当前标签|
|M16|Latency|各阶段wall time/队列|调度/性能报告|
|M17|RuleHealth|规则触发/错误/陈旧度|DecisionGate健康门|
|M18|Failure|失败层与实验动作|专家/生成器；支持数|
|M19|Teacher|旧教师预测及独立回放|旧能力适配/消融；有消费者才发布，未迁移不删除|
|M20|Freeze|每策略每期冻结/结算状态|资格/审计/报告；迟到不可补填|

F01—F24、E01—E16、I00—I19、每个原子/分子/矩阵都要逐一进入能力注册表，运行状态与效果状态分列。注册数量不能代替实际训练调用。矩阵名称相同但schema不同必须保留namespace与版本。

## 5. 校准与主链

`LiveShadowsR27.calibrate`当前只处理ACTIVE，而R27正式影子为空。扩为已冻结的确认候选和可评估观察候选，REPLAY拟合与FUTURE验证严格分开。fit、validation、application三个时间界限落库；校准模型hash属于策略身份。验证不通过可以继续观察，不能用回放ECE自授证。

主链选择器作为完整meta-policy单独冻结评价：已合格成员不保证“每期择优挑其中一个”的组合也合格。保留单一成员直接上主链的合法路径；成员组合择优规则需独立确认。跨库后 `MainlineBridgeSU2.R27_INTENT_SQL` 的旧同库JOIN改为校验过的projection，不静默查空。只有DecisionGate最终授权REAL，SettlementEngine唯一正式结算。每条REAL绑定当期freeze、certificate、selector、model、赔率版本；相同issue唯一索引。
