## 主要定案

保留真实历史训练和已有效功能；持续运行不以充电/闲时为条件；旧算法能力先迁移，重复调度后撤除。把I08与AtomNet实际接通，研究模型版本与时间隔离；完整策略包含选位、K3、ACT、更新及校准，不能把随机数学式数量当能力。确认队列不因短期换榜被挤掉；自然证据与研究数据严格分离。

≥34%命中、约15%以上频率及稳定品质是目标，不是已实现结论。达标资产须走证书→主链→真实结算；未达标须继续研究并报告差距，不能改统计口径凑达标，也不能因本次未找到优势断言所有方法永远无效。
