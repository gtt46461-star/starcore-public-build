# 02 各能力功能效果诊断表

每个功能一行：**它是干什么的 → 报告里实测效果 → 为什么不够强 → R28 怎么改（卡号）→ 用哪项指标验收（docs/09）**。

"为什么不够强"统一分三类根因：

- **【数据】** 开奖无可利用规律，功能再强也只能测出 30%。软件改不了，只能如实测量。
- **【工程】** 功能没有真正跑起来、跑得太慢、被别的模块挤掉、或者输出没人消费。R28 必须修好。
- **【评价】** 用错了尺子（少样本排行、训练集曲线、无对照），把运气当本事。R28 改尺子。
