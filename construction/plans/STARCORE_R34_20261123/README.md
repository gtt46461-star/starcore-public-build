## 本次事实结论

- 三份报告均来自源码提交273641e838e0b8dd842b42a67a674e184942a30a、版本577311095。仓库main的app不是这次现场返修的默认替代前态。
- 抓取部分推进；旧R26反馈也有增量。但最后报告开奖水位288，预测/严格OOS停在119；当前R27策略、未来机会、证书均0。R952只有一个NURSERY候选，其若干当前训练/冻结链表为0，不能用旧R26训练记录替它签收。
- HTTP原body与trim后body摘要不一致是可复现源码缺陷；现场还发生receipt写入BUSY。报告不含失败HTTP原体，因此不把每一次现场错误都硬归因于空白。
- writer故障积压、迁移长事务、历史连续性不足和候选旧ABI封存后缺冷启处理器共同形成阻断链。不同对象的最终数值问题仍须各自原件复演。
- “心跳运行中”和“业务水位推进”不同；本次caught异常栈也不能直接当成线程退出。
