# STARCORE R27 最终施工方案（2026-10-28）

R27 是当前 **唯一执行规范**。它以 10.28 20:35 最新检测报告（`R26-2026.10.28-reportfix2`，versionCode 577271029，源码 `4dcddd2`）和最新软件源码（`fix/r26-report-export-20261028@1713d11`）为依据，修订并取代 R26 中与之冲突的条款；R26 的24家族/16专家数学合同（R26 `docs/04`）继续作为实现规范引用。

## 1. 一句话结论

当前软件"看起来在跑但样本少、看不到进化、误差乱跳、证书永远为0"，主要是 **工程断点** 造成的：每次升级把证据清零、研究只拿到单核约4%的CPU、历史回放从未运行、图表读的是已停写的旧表、校准一行迟到就整批作废、资格窗口要等69,120期。R27 把这些逐一修通，让系统真正 **实时运行＋用全部历史数据秒级训练和淘汰＋每天上百代可见的进化＋平稳可读的误差曲线＋自动生成的胜率真相报告**。

同时必须如实说明：用仓库自带1万期数据实测（`tools/r27_null_baseline.py`），13种常见思路逐期前推全部在30%±1%；进化搜索在训练集上"一代比一代强"（31%→33%），在打乱标签的数据上同样如此，留出未来回到30%。所以 R27 规定"变强"只认留出数据和实时未来上的检验，并强制并列负对照。系统做出来后最可能给出的质量结论是"未发现显著优于随机的策略"——这是正确输出，不是故障。详见 `docs/01`。
