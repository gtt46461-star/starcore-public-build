## 11.3 与 R26 128卡的关系

R26 的 128 卡保留为验收义务清单。R27 卡在 `r26_refs` 字段写明覆盖的 R26 卡；R26 中与 R27 冲突的条款按 README 第4节裁决。R26 第04章（24家族/16专家数学合同）继续有效，作为 R27 思路族与 AST 叶子 `family(Fxx)` 的实现规范。
