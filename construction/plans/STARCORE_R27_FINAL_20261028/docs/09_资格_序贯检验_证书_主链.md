# 09 资格、序贯检验、证书与主链（R27-B08）

## 9.1 不变的规则（照抄现有，R27 不改）

- 固定单位置K3；每期最多一条 REAL；`DecisionGateEngine` 唯一真实授权；`SettlementEngine` 唯一正式结算。
- 主链准入：有效独立证据 HR ≥ 34% 且质量门通过（样本、校准、配对证据、结构、有效期）。
- 无频率配额；未达证据门不出手；禁止追期、马丁、加倍、补单、备用真实链、动态K、多位置真实。
- 研究可以全功能持续运行，**REAL 必须满足质量与用户模式**。

## 9.2 要改的：从"等 69,120 期再看一次"到"序贯检验"

现状：`QualificationWindowR26.LENGTH=69120, STRIDE=720`，第一次看结果要约48天（00章0.8）。

R27：对实时影子池中每个策略，使用 **随时有效（anytime-valid）的序贯检验**，每结算一期更新一次，可以随时停止，错误率保证不因"多看"而膨胀。

### 9.2.1 检验对象

单期超额 u_t = ACT_t ×（hit_t − 0.30）∈ [−0.3, 0.7]，只在 FUTURE（赛前冻结、开奖后结算）样本上计算。

### 9.2.2 检验统计量：e-过程（betting martingale）

- 零假设 H0：E[u_t | 过去] ≤ 0（不比随机好）。
- e-过程 `E_t = ∏_{s≤t} (1 + λ_s · u_s)`，λ_s 由过去数据可预测地选取（aGRAPA：λ_s = clip(μ̂_{s−1}/σ̂²_{s−1}, 0, 0.5/0.7)），初值 E_0 = 1。
- 判定：
  - `E_t ≥ 1/α_i` → **拒绝 H0**（证据表明优于随机），进入"资格候选"；
  - 同时对反向假设（E[u_t] ≥ δ_min，δ_min = 0.15×(0.34−0.30) = 0.006，即 HR 34% 在15%出手率下的每期超额；出手率不同时按该策略预注册出手率换算）维护第二个 e-过程，`≥ 1/α_i` → **判定不优于目标**，退出影子池回档案。
- α 分配：全局 α_root = 0.05，按策略进入实时影子池的全局序号 i 分配 α_i = α_root × 1/((i+1)·ln²(i+1)) / C（C=Σ_{i≥1} 1/((i+1)ln²(i+1)) ≈ 2.11，使总和=α_root）。i 永不重置，升级不重置——等价策略沿用原序号（第08章）。这保证"无论试多少个策略，错误授证的总概率 ≤ 5%"，满足 R26 已有的"永久预算"要求，并且不需要把窗口拉到69120期。该分配比 1/i² 衰减慢，第1000个进入影子池的策略 α_i≈5e-7，所需期数约为第10个策略的2倍，而不是成百倍。

### 9.2.3 需要多少期（规划值，非承诺）

若某策略真实 HR=35%、出手率15%：u 均值 μ≈0.0075/期，方差 σ²≈0.15×(0.35×0.49+0.65×0.09)≈0.0345；e-过程每期对数增长率约 μ²/(2σ²)≈0.00082。在 α_i≈0.003 时，期望停时约 `ln(1/α_i)/0.00082 ≈ 5.8/0.00082 ≈ 7,100` 期 ≈ **5天**；α_i≈5e-7 时约 17,700 期 ≈ 12天。若真实 HR=30%（无优势），反向检验在相近量级内判退。69120期窗口被替代，统计保证不降低。

### 9.2.4 与 R26 条款的关系

| R26 条款 | R27 处理 |
|---|---|
| 固定 69120 期窗口、720 步长 | 删除，改 9.2 序贯检验；720 期分块统计保留为"稳定性"质量门（最差块 HR ≥ 26%） |
| 配对下界 LCB ≥ −δ 非劣、> 0 改善 | 保留，用于第05章代际比较与冠军替换 |

## 9.3 证书与主链

1. 序贯检验拒绝 H0 → 写 `r26_qualification_result(look=当前期, evidence_digest)` → `CertificateSU2.maintain` 检查质量门：
   - HR 点估计 ≥ 34%（**现有门槛不变**）；
   - FUTURE 已结算出手 ≥ 250（R26 最低门槛保留）；
   - 校准 ECE ≤ 0.04（分层）；
   - 720 期分块最差 HR ≥ 26%；
   - 最长连挂在预注册窗内 ≤ 观察目标（6），第7挂触发风险响应（R26 规则保留）；
   - 语义ABI等价（第08章）；
   - 显著优于同期负对照（I00 冠军与打乱标签冠军）。
2. 全部通过 → 证书 `ACTIVE`，有效期 24 小时，到期按最新证据续签；任何一项失败 → 撤销，原因写 `r26_certificate_revocation`。
3. `MainlineBridgeSU2.chooseIfDue`：在有 ACTIVE 证书的策略中按"e 值 × 校准质量"选一个；绑定到 `DecisionGateEngine`；`DecisionGateEngine` 按现有规则决定该期是否 REAL。
4. 没有 ACTIVE 证书 → 生产保持 `PRODUCTION_FALLBACK|NO_VALID_CERTIFICATE`（现状），界面显示"暂无合格策略，原因：……（列出最接近的3个策略各差哪一项）"。
