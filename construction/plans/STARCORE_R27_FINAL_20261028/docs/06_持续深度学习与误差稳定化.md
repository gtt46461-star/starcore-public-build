# 06 持续深度学习与误差稳定化（R27-B06）

用户观察："深度学习训练误差波动太大，没有持续变好。" 第00章0.9已给出原因；本章给修法，并重新定义"怎么看它是不是越学越准"。

## 6.1 现状与根因（复述要点）

| 问题 | 位置 | 后果 |
|---|---|---|
| 每期只用1个样本做1次SGD | `AtomicToolWorldR943.java:139` | 权重随每个样本大幅摆动 |
| 没有历史预训练，88个样本就是全部 | 同上；样本只来自赛前冻结上下文 | 模型几乎没学到东西 |
| 冻结上下文赶不上截止 → 0669后0个新样本 | lane0 `TARGET_DEADLINE_PASSED_NO_RETROACTIVE_CAPTURE`；lane14 `WAIT_NEW_FROZEN_ATOM_LABEL` | 训练停止，曲线停在0669 |
| 图表滚动20期、写死0.21 | `ChartsRepositoryR83.networkBrier()` | 纯噪声即可在0.11—0.35间摆动（第01章E） |

## 6.2 新模型 AtomNetR27

- 输入：240原子中 `productionScoreEligible` 的165个，按7个原子组做掩码汇总（保留现有 `groupFeatures` 语义），另加每个原子组的原始值（可配置开关），共 7 或 7+165 维。
- 输出：每个候选K3的命中概率（与现有 `network_probability` 同义），以及每位置10号码的分布（新增，便于与其他家族统一 readout）。
- 结构：7(或172) → 32 → 16 → 1/10，ReLU，dropout 0.1（只训练时），参数 ≤ 7k。
- 损失：二元交叉熵（K3命中）＋ 0.5×多类交叉熵（位置号码），L2=1e-4。

## 6.3 训练流程

1. **历史预训练**（回放，第03章）：在 H_TRAIN 上按期生成 PIT 原子特征（`FeatureCacheR27`）与标签，Adam(lr=1e-3)，batch=64，余弦衰减到1e-5，最多20 epoch，早停看 H_SELECT logloss（patience=3）。5000期×10位置≈5万样本，手机单线程约数十秒。
2. **留出检查**：在 H_HOLDOUT 上计算 logloss、Brier、BSS（见6.4）、ECE。
3. **实时续训**：每期开奖后，用该期 PIT 特征做 **1个小批量**（本期样本 + 从最近2000期随机回放63个，经验回放），lr 固定为预训练末值×0.1。这样单个样本不会把权重拽偏，又能跟随最新数据。
4. **样本不再依赖赛前冻结**：训练样本从开奖表按 PIT 规则直接计算（开奖后计算 ≤ t−1 的特征是合法的训练样本）。赛前冻结仍然做，但它只用于"实时成绩（FUTURE）"统计，不再是训练样本的唯一来源。这直接消除"冻结赶不上→训练停"。
5. **防退化**：每 720 期在 H_HOLDOUT 新块上评估；若 logloss 比上次评估差超过 2 个标准误，回滚到上一检查点并把在线学习率减半，记 `ROLLBACK_DEGRADED`。

## 6.4 误差该怎么看：新图表定义

替换"滚动20期 Brier"为以下三张（旧图保留为"短期波动（仅供参考）"折叠在下方）：

### 图A：累计逐期误差 vs 基线（主图）

- 横轴期号，纵轴 **Brier 技能分 BSS = 1 − Brier_model / Brier_base**，Brier_base 是同期"常数0.30"预测的 Brier（理论0.21，按实际命中频率实时算）。
- 画三条：累计 BSS（从实时开始）、EWMA（半衰期200期）、以及 **95%置信带**（按配对差 d_t = (p_base−y)² − (p_model−y)² 的累计均值 ± 1.96×标准误）。
- 读法写在图下：**置信带整体在0以上才说明比"随便猜30%"更准；带子包含0说明还看不出区别；在0以下说明比基线差。** 不再说"曲线下降就是越学越准"。

### 图B：滚动200期 Brier 与噪声带

- 滚动窗口200期；同时画"无预测能力模型在200期窗口下的95%波动带"（按当期命中频率模拟，第01章E方法），让用户一眼看到波动是否超出噪声。

### 图C：训练损失与留出损失

- 历史预训练每个 epoch 的 H_TRAIN 与 H_SELECT logloss；实时阶段每 720 期一个 H_HOLDOUT 点。两条线分开说明是否过拟合（训练降、留出不降 = 过拟合）。

## 6.6 "持续深度学习"的验收口径

| 指标 | 目标 | 说明 |
|---|---|---|
| 训练不中断 | 任意连续 60 分钟内，AtomNet 实时续训步数 ≥ 55（每期1步，允许断网缺期） | 解决0669后停更 |
| 预训练完成 | 安装/升级后 10 分钟内完成历史预训练并在报告记录 epoch 曲线 | — |
| 图A 置信带 | 必须显示；N<200 时显示"样本不足"而不是画线 | — |
| 过拟合检测 | 训练/留出 logloss 差值 > 0.02 时图C 标红 | — |
| 质量结论 | 由图A置信带决定：带下界>0才可写"优于基线" | 不承诺一定>0 |

**如实提醒：** 按第01章数据，最可能的结果是图A置信带长期包含0（模型与基线一样准）。这时曲线会比现在 **平稳得多**（因为窗口与样本量都大了），但它不会"持续下降"。平稳地贴着0，就是这类数据的真实样子。
