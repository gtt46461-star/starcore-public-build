# 07 原子世界、分子、矩阵、校准与其他功能（R27-B07、R27-B09）

## 7.1 原子世界

现状（报告）：登记原子240，可评分165，研究代理40，审计身份15，开奖后证据20；新原子提案0；165个原子 BrierGain≈0（如 2.1e-4，下界 −0.0044）；lane14 `WAIT_NEW_FROZEN_ATOM_LABEL`；lane15 分子 `activeTypedAtoms=0,newMolecules=0`。

### 修改

1. **原子评分改用回放**：每个可评分原子在 H_TRAIN+H_SELECT 上计算"单原子打分→K3"的配对超额与 BrierGain，以及在 H_HOLDOUT 上的复核值。样本量从88期变为数千期，置信区间缩小到当前的约1/7。
2. **原子状态**：`USEFUL`（H_SELECT 与 H_HOLDOUT 下界都>0）、`NEUTRAL`（区间含0）、`HARMFUL`（上界<0）、`MASKED_MISSING`（缺失>10%）。只有 `USEFUL` 原子在生成器里有更高被选概率（权重×2），`NEUTRAL` 正常，`HARMFUL` 权重×0.25（不禁止，保留对照）。
3. **新原子提案**（之前为0）：每 50 代，从存活策略 AST 中提取出现频率最高、且消融贡献最大的子树（深度≤3），作为"派生原子"登记（`semanticTier=DERIVED`），经泄漏测试后进入叶子集合。派生原子身份 = 子树规范哈希。
4. **开奖后证据原子（20个）与研究代理**：继续隔离，生成器不可引用（类型系统强制 `stage=POSTDRAW` 不能出现在 predict 路径）。

## 7.2 分子（原子组合）

- 定义：2—4个原子的类型合法组合（乘积、比值、条件选择、差分），即深度≤2的 AST 片段。
- 生成：从 `USEFUL`/`NEUTRAL` 原子中按互信息（在 H_TRAIN 上与命中标签）采样配对；每代生成 32 个分子，像策略一样过回放与淘汰，存活分子成为叶子。
- 修复 lane15 `activeTypedAtoms=0`：分子输入从原子回放评分表取，不再等冻结标签。

## 7.3 矩阵（R26 的 100面 / 1200动作 / Rank1—3）

- **100面**：10位置×10号码的概率面，每期每个影子策略都输出并冻结（`R26_FROZEN_SURFACE.json` 规范不变）。
- **1200动作**：每位置 C(10,3)=120 个K3组合 ×10位置。概率 = 同位置三个号码边际之和（R26 规范，保留）。
- **矩阵快照 `MatrixStoreSU2`**：由 ResearchPool 在结算后准备、P0 冻结；`diagnosis` 任务只读快照做诊断。
- **父子矩阵 `MatrixSourceRouterCP12`（读 `r974_model_lineage`）**：改读 `r27_lineage`。
- **一致性检查**（新增单元测试）：每位置10个概率和=1；1200动作概率由100面推导，误差<1e-9；Rank1/2/3 即最高的三个号码。

## 7.4 校准链修复（00章0.7）

`CandidateCalibrationR932` 现规则：241个"连续评价期"一行不合格就整批作废。修改为：

1. **逐行剔除而非整批作废**：`fetch_time >= openTime`（迟到）或该期没有评价记录的行，记 `EXCLUDED_LATE`/`EXCLUDED_GAP`，**跳过这一行继续收集**，直到攒满 120（拟合）+1（隔离）+120（验证）个合格行。迟到/缺失计数写入研究记录并进入机会分母，不伪造。
2. **校准数据来源扩展**：校准拟合段允许使用回放 H_SELECT 上的逐期输出（同一策略、同一在线规则，见第03章3.3 同口径保证），验证段必须是 FUTURE（实时冻结）样本。这样校准拟合不再等待241期实时数据，验证仍然是真实未来。
3. **校准方法**：保留 `ResearchLogisticCalibrationR932`（Platt）；样本 ≥ 1000 时允许等渗回归作为对照；按位置、出手档分层报告 ECE。
4. 失败原因必须细分：`EXCLUDED_LATE`、`EXCLUDED_GAP`、`IDENTITY_DRIFT`、`INSUFFICIENT_ROWS`，不再统一 `BLOCKED_INVALID_INPUT`。

修改位置：`CandidateCalibrationR932.java:238-240,276-277`；`GlobalResearchScheduleR932.java:210`。
