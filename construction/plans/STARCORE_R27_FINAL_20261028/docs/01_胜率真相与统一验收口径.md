# 01 胜率真相与统一验收口径

这一章回答"到底胜率什么样、什么原因"。它不是为了劝退，而是为了让后面所有施工有同一把尺子：**系统做出来的任何"更强"，都必须在这把尺子上量出来，否则就是假的。**

## 1.1 基准线：为什么是30%

固定单位置、选3个号码（K3）。一期开出10个号码的一个排列，某个位置上出现的号码是10选1。只要开奖对过去是独立的，任何选法命中概率都是 3/10 = **30%**。这就是所有图上的"随机基线"。

- 命中率高于30%且在 **没参与挑选的未来数据** 上持续高于30%，才叫有优势。
- 冷热、遗漏、转移、跨位置……任何规则如果数据真的独立，长期都会回到30%。

数据源是区块链哈希开奖（报告接口 `api.duoqu.online`，每期带区块号与哈希）。此前在本项目里已做过的回测结论是：预测与基线、与随机数据对照在统计上无法区分。本章用仓库自带数据重新做了一次，可复现。

## 1.2 本次实测（仓库 `research_data/ethpk10_draws_20260316_201059.csv`，10,000期）

工具：`tools/r27_null_baseline.py`，结果：`results/r27_null_baseline_results.json`。只用 t−1 及以前的数据预测第 t 期（逐期前推，无未来泄漏），第1位置固定K3。

### A. 13种常见思路，9,500期逐期前推

| 策略 | 命中率 |
|---|---:|
| 随机选3个 | 30.00% |
| 热号（近20/60/240/1000期） | 30.35% / 30.36% / 30.35% / 29.52% |
| 冷号（近20/60/240/1000期） | 29.94% / 29.36% / 30.28% / 30.41% |
| 最长遗漏 / 最短遗漏 | 29.66% / 30.27% |
| 一阶转移（马尔可夫） | 28.99% |
| 跨位置滞后（第2位上期→第1位本期） | 29.74% |

9,500期的标准误是 ±0.47 个百分点。**全部落在 30%±2个标准误之内。**

### B/C. 进化搜索：训练集上"一代比一代强"，未来上回到30%

64个个体、30代、精英保留＋交叉＋变异，个体是11个特征的线性打分公式。前4,850期训练与挑选，后4,850期当"未来"。

| 代数 | 训练集最好 | 训练集平均 |
|---|---:|---:|
| 第0代 | 31.0% | 29.8% |
| 第10代 | 32.7% | 32.0% |
| 第29代 | 33.0%—33.2% | 32.4% |
| **最终冠军在留出未来上** | — | **29.5%—30.3%** |

关键对照 C：把训练标签 **随机打乱**（数据里不可能有任何规律）后用完全相同的进化流程：训练集冠军照样升到 **32.8%**，留出未来 30.6%。

**结论：在训练数据上"一代比一代强"，在打乱标签上同样会出现。它只证明搜索器会拟合噪声，不证明策略变强。** 这就是 R27 把"代际变强"的定义改为"留出未来上配对比较通过"的原因（第05章）。

### F. 正对照：如果数据里真有规律，同一套流程找得到吗？

把真实数据人为植入一个弱规律（第1位以概率 q 换成上一期第2位的号码，排列仍合法），其余流程完全相同：

| 植入强度 q | 训练集冠军 | **留出未来** |
|---:|---:|---:|
| 0（真实数据） | 33.0% | 29.5% |
| 0.05 | 34.1% | **33.5%** |
| 0.10 | 38.2% | **36.9%** |

有规律时，留出未来的成绩明显高于30%并接近训练成绩；没有规律时，留出未来回到30%。**这说明"留出段检验"这把尺子是灵的：它既能认出真信号，也能拆穿假提升。** R27 的进化、晋升、报告全部按这把尺子执行（第05章5.1、第12章H06/H07）。

### D. 很多算法同时跑少量期数时的"假高胜率"

43个毫无优势的算法，各跑 N 期，取其中最好的那个：

| 每个算法样本量 N | 最好者命中率中位数 | 95%分位 | 最好者≥50%的概率 |
|---:|---:|---:|---:|
| 20 | **55.0%** | 65.0% | 87.8% |
| 32 | 46.9% | 56.3% | 44.9% |
| 120 | 39.2% | 43.3% | 0.01% |

报告里的 11/20（55%）、11/19（58%）、13/32（41%）恰好就是这张表的样子。**少量样本的排行榜第一名，几乎一定"看起来很高"。**

### E. 滚动20期 Brier 在纯噪声下的波动

88个已结算样本、无预测能力的模型：滚动20期 Brier 典型最低0.147、最高0.289；5%—95%：0.108—0.349。截图曲线（0.078—0.275）大部分在这个范围里。见第06章。

## 1.3 胜率上不去的原因（按影响排序）

1. **数据层面**：开奖由哈希决定，当前任何已测试的特征都没有超出30%的稳定信号（1.2-A）。这一条软件改不了，只能如实测量。
2. **工程层面使样本少、结论慢**：升级清零（00章0.2）、研究线程饥饿（0.3）、回放从未运行（0.4）、校准整批作废（0.7）、69120期窗口（0.8）。这些让系统连"有没有优势"都测不出来。R27全部修。
3. **评价层面容易自欺**：少样本排行榜（1.2-D）、训练集进化曲线（1.2-B/C）、滚动20期误差（1.2-E）。R27把这些从"成绩"降为"过程指标"，并强制配负对照。

## 1.4 R27 统一验收口径（所有图表、报告、主链共用）

| 名称 | 定义 | 用途 |
|---|---|---|
| 机会数 N_sched | 预定期数（含断网、迟到、缺失） | 分母，不得剔除坏期 |
| 出手数 N_act | 策略在该期给出可执行K3的期数 | 频率 = N_act / N_sched |
| 命中率 HR | 命中数 / 已结算出手数 | 必须同时报 Wilson 95% 区间 |
| 超额 u_t | ACT_t ×（hit_t − 0.30） | 配对比较用 |
| 运气上限 E_max(N,k) | k个零优势策略各跑N期时最好者命中率的期望（表1.2-D） | 排行榜旁边必须显示 |
| 回放成绩 REPLAY | 在历史训练段/挑选段上的逐期前推成绩 | 只用于淘汰、排序、找方向，**不进主链** |
| 留出成绩 HOLDOUT | 在最近、未参与挑选的历史段上的成绩（第03章） | 代际比较、晋升到实时影子 |
| 未来成绩 FUTURE | 赛前冻结、开奖后结算的实时成绩 | 唯一进入资格、证书、REAL 的成绩 |
| 负对照 NULL | 打乱标签进化冠军、随机基线族在同一期的成绩 | 必须与冠军并排展示 |

**一个候选被叫作"高胜率"，必须同时满足：** FUTURE 样本上 HR 的 Wilson 下界 > 30%，并且显著好于同期负对照，并且通过第08章序贯检验。在那之前，界面一律显示"观察中（REPLAY/HOLDOUT 成绩不代表未来）"。

## 1.5 本方案对目标的承诺边界

- R27 承诺的是：**系统真正持续运行、真正用全部历史数据快速训练和筛选、真正大量创造/变异/融合/淘汰、真正可见、真正如实测量**，并且一旦存在稳定优势，能在数天而不是数十天内把它识别出来送进主链。
- R27 **不承诺** 35%/37%/40% 一定达到。按1.2的数据，最可能的结果是：系统持续运行、快速淘汰、在 FUTURE 上报告"未发现超过30%的稳定策略"。这本身就是正确输出，不是故障；方案禁止为了让数字好看而放松测量（例如把 REPLAY 成绩当成 FUTURE、删掉负对照、把滚动20期当学习证明）。
- 主链规则保持现状：有效独立证据 HR≥34% 且质量门通过才可 REAL，每期最多一次，无频率配额，禁止追期、马丁、加倍、补单。R27 不新增更严的门槛，也不放松已有门槛；只把"永远走不到门槛前"的工程断点修通。
