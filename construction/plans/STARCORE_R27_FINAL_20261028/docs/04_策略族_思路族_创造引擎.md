# 04 策略族、思路族与创造引擎（R27-B05 上半）

用户要求：持续设计大量不同的策略、方法、算法、公式；有各种策略族、思路族；创造出可执行的完整策略。

R27 的做法：**所有策略都用同一种可执行、可序列化、可变异的"策略程序"表示；"思路族"是生成这些程序的不同生成器；R26 的 24 家族是程序里可调用的"模型积木"。** 这样创造、变异、融合、淘汰、记谱系、上图表都是同一套机制。

## 4.1 统一策略对象 PolicySpecR27

一个完整策略 = 五段，缺一不可：

```
PolicySpecR27 {
  inputs:     使用哪些原子/特征组、窗口尺度（8/32/128/512/2048/5000）、缺失策略
  model:      打分程序（AST）或家族模型引用（F01—F24 + 超参）→ 输出每位置10个号码的分数
  readout:    分数 → 合法概率面（10×10，每位置和为1；可选排列一致化 F17 精确核）
  selector:   概率面 → 是否出手、哪个位置、哪3个号（K3）；出手阈值、位置规则
  updater:    在线学习规则（学习率、遗忘、何时重拟合）
  meta:       思路族、父代、出生期、数据集哈希、随机种子、创造原因（文字）
}
```

- 序列化：规范化 JSON → `policyHash = SHA256(规范文本)`，沿用 `StrategyPolicyIdentityR26`/`PolicyIdentityLedgerR26`（无损，不截断小数）。
- 可执行检查（出生前必须过）：类型检查（分数、概率、风险不可混用）、数值范围、因果滞后 ≥ 1、成本上限（单期预测 ≤ 5ms，状态 ≤ 4MiB）、输出合法（每位置概率和=1±1e-9、K3三个号互不相同）。
- 行为去重：在固定 500 期探针集上算出手模式与 K3 选择的签名（沿用 `BehaviorSignatureSU1`），与现有候选的 Jaccard ≥ 0.95 视为重复，不进入回放（记 `DUPLICATE_BEHAVIOR`）。

## 4.2 打分程序 AST：运算符集合

叶子（终端）：

| 类别 | 叶子 |
|---|---|
| 频率 | `freq(pos, W)`、`freqAll(W)`（全位置）、`freqDecay(pos, halfLife)` |
| 遗漏 | `gap(pos)`、`gapRank(pos)`、`meanGap(pos,W)` |
| 转移 | `trans1(pos)`（上一期同位置号码→本期）、`trans2(pos)`、`crossLag(srcPos, lag)` |
| 结构 | `sumBucket`、`oddEven`、`bigSmall`、`repeatFromLast`、`neighbor(±1)` |
| 状态 | `regime(k)`（F08/F10 状态概率）、`runLength`（BOCPD 运行长度） |
| 检索 | `knnSimilar(W, k)`（F20 片段检索：历史中与最近 W 期最相似的 k 个片段的下一期分布） |
| 模型 | `family(Fxx, params)`：调用 24 家族之一的输出分数 |
| 常数 | 可训练常数 `c_i` |

内部节点：`+ − × ÷(安全) max min neg abs log1p sqrt sigmoid tanh rank zscore softmax(τ) ifGreater(a,b,x,y) mix(α,x,y) lagDiff ema(x,α)`。

约束：深度 ≤ 6、节点 ≤ 40、可训练常数 ≤ 12；超出则出生失败（`TOO_COMPLEX`）。

## 4.3 思路族（生成器）——每个族是一种"想问题的方式"

每个思路族 = 一个生成器 `generate(rng, context) → PolicySpecR27`＋该族专属的变异算子＋该族的先验。思路族之间公平分配出生名额（每族每代最少 2 个），再按"该族近期在 H_SELECT 上有多少个存活者"给额外名额（上限是最低名额的 4 倍，防止一族垄断）。

| 编号 | 思路族 | 核心想法 | 生成方式 | 主要调用家族 |
|---|---|---|---|---|
| I01 | 频率回归族 | 冷热号是否有持续性/回归性 | 随机选窗口、衰减、冷/热方向、组合 | F09、F21 |
| I02 | 遗漏周期族 | 号码间隔是否有周期 | gap、meanGap、gapRank 的非线性组合 | F11、F12 |
| I03 | 转移链族 | 上一期/上两期对本期的条件分布 | trans1/trans2/高阶稀疏转移 | F01、F21 |
| I04 | 跨位置关系族 | 其他位置对本位置的滞后影响 | crossLag 选源位置与滞后、交互项 | F01、F19（张量分解） |
| I05 | 排列一致族 | 一期10个号互斥，联合考虑全排列 | 一元排列能量精确核、因子图 | F02、F17 |
| I06 | 状态切换族 | 数据是否存在不同"体制"，体制内规律不同 | regime/runLength 门控两个子打分 | F08、F10、F20 |
| I07 | 相似片段检索族 | 历史上类似的局面之后发生什么 | knnSimilar 的 W、k、距离度量 | F20、F11 |
| I08 | 神经表示族 | 让网络自己学特征 | 原子组掩码 + 小网络（≤ 20k参数） | F03—F07、AtomNet |
| I09 | 符号公式族 | 自动写出可读公式 | 随机AST生长（ramped half-and-half） | F13、F14 |
| I10 | 失败修复族 | 针对上一代冠军的失败期做改进 | 读取冠军在 H_SELECT 的失败簇（位置/状态/窗口），提出局部结构修改 | F22，专家 E01—E16 |
| I11 | 组合互补族 | 多个弱且不相关的策略组合 | 从档案选低相关成员做加权/门控融合 | F24 |
| I12 | 旧资产族 | 原多集合×多位置交叉交集等旧策略 | 原执行器复现为程序；参数再拟合 | F23 |
| I13 | 出手选择族 | 不改预测，只改"何时出手、出哪个位置" | 改 selector：阈值、位置轮换、置信度门 | 任意 |
| I00 | **随机基线族（必须保留）** | 对照组 | 每代生成与冠军同出手率的随机选号策略 | 无 |

I00 与第05章的"打乱标签进化"一起构成负对照：任何族的冠军若不能在 H_HOLDOUT/LIVE 上显著优于 I00，就不能被叫作"更强"。

## 4.4 16 专家的角色（与 R26 一致，接到创造流水线上）

R26 的 E01—E16（`ExpertWorkshopR26`）改为"提案者"：每个专家读取冠军/失败簇的诊断，产出 `ProposalR27{目标失败簇, 假设, 结构改动, 预期机制, 反证条件}`，提案经 4.1 检查后进入出生队列，记 `meta.reason`。专家提案在出生名额中占 ≤ 25%，其表现（提案存活率、晋升率）进报告"专家"章。

## 4.5 创造流水线（每代）

```
出生配额分配（按思路族）
  → 生成 PolicySpecR27（生成器 / 变异 / 交叉 / 融合 / 专家提案）
  → 可执行检查（类型、范围、因果、成本、合法输出）  失败→ 记 BIRTH_REJECTED(原因)
  → 行为去重                                       重复→ 记 DUPLICATE_BEHAVIOR
  → 登记 r27_policy、r27_lineage（父代、操作、原因）
  → 回放：H_TRAIN 训练 → H_SELECT 评估（第03章）
  → 淘汰赛（第05章）
```

默认规模（可在设置中调整，受第12章实测约束）：每代出生 128 个，活跃种群上限 256，档案（含淘汰者）上限 20,000 条（只存 spec、成绩、谱系，不存大权重）。一代在中端机2线程下目标 ≤ 10 分钟，即每天 ≥ 100 代。
