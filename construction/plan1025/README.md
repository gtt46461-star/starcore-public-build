## 修正的方案缺陷

1. SQL 生成时按 SQLite 语句边界解析，并在压缩空白前移除注释；每次生成直接执行全部生产 DDL，防止行注释吞掉列定义。
2. 原 R13 基因组表仅接受 `SU2|` 和 2048 字符。以研究写事务重建约束，保留旧行，支持委员会和绑定训练参数的阶段策略；失败整体回滚。
3. HUB 校准检查点拆成独立行，实时集合最多 32 策略、48 个校准成员；当前主链在 SQL 限行之前排在首位，集合减少时也重建运行时。
4. P50 统计先于原始数据保留策略执行；增加终身折叠游标，避免已折叠块在旧原始行仍存在时被重新累计。
