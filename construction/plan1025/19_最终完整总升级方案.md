## 0. 一页结论

**方案是什么**：50 个项目、10 个批次（A–J），11 个补丁按序施工；新增 Java 类约 42 个、锚点修改现有文件 15 个、删除 0 个、整文件重写 0 个（旧车道全部保留，这是“永不劣于旧版”的前提）。

**系统能力（全部已实现，Java 与 Python 逐位/逐字节一致）**：
- 原子世界 → 可学习的底层：165 个评分原子 + 112 个状态原子 + 交叉项 + 学习型分子，权重每期在线学习（P39/P43）；任何策略可拆到原子并从原子重建（P47）；研究记忆让系统越用越会挑方向（P44）。
- 八个数学家族 + 两个区制记忆族：多尺度 Dirichlet、变点、隐区制、条件对数线性、关系可靠度、趋势 Kalman、原子网络、区制记忆 REGMEM / 关系区制 RELMEM（P10–P17、P39、P48）；先在线校准再融合（P36）。
- 持续创造：13 种结构算子按实测成效配比，失败诊断→定向修复，父代进名人堂不丢弃，经验贝叶斯裁判选委员会冠军，F15 / F30 / F100 三个频率层（P20–P26、P37–P41）。
- 阶段与窗口：原子延续/转向矩阵（连出大小单双 3–10 期、偏多偏少、原子极端值之后下一期是延续还是反转，每 500 期证实一次）、阶段识别与“阶段 × 置信度”择期、观察—出手（P49）。
- 每期全量：每个策略每期都冻结、都结算、都训练（不出手的期也算）；历史快速回放与实时同一套代码（P05–P09）。
- 主链：用户原方法 XI（多位置多号码交叉交集）是起点和底线；新策略只有在同一批期次上显著优于 XI 才接管（IPM，P03/P30），因此**永不劣于旧版**。
- 检测报告 = 升级诊断书：每 500 期自动写出差在哪、缺什么能力、怎么升级、升级后预计到多少、怎么验证；升级动作自动开影子挑战者实盘配对验证；问题台账跨报告合并（P50）。
- 体积与内存有界、重要内容完整保留：报告失败不再复制整库、配额执行（P31–P34）；所有每期增长的表有寿命，终身统计精确保留；实时集合与校准环有上限，HUB 检查点拆分（P50）。

**实测（同数据、同种子、冻结后前推；已知真相世界用留出种子 2）**：
- 区制世界（理论上限 15% 层 45.9%）：15% 层前推期望命中 R13 41.2% → R15 40.8% → **R16 41.8%**；R16 主链实际 36.1%（2779 次，频率 27.8%）。
- 跨位置关系世界（上限 37.5%）：R13 32.5% → **R16 35.8%**（实际 34.8%，2175 次）；主链 33.2%（频率 23.9%）。
- 真实开奖（5.4.3 报告 4,995 期，冻结前推 1,995 期）：主链 = XI 33.4%（323 次，频率 16.2%，95% 下界 29.3%）；新冠军 F15 33.3%（117 次）、F30 34.5%（177 次）——都没有在样本外显著超过 XI，主链按规则留在 XI。
- 同一真实数据时间打乱（对照，任何结构都被破坏）：主链 30.0%（297 次）——系统不报假优势。
- 升级诊断书判定：区制世界 **A**（探针 REGMEM 预计 39.0%，多重比较校正后下界 36.6% > 35%）、跨位置世界 **B**（RELMEM 预计 34.8%）、真实开奖 **D**、打乱对照 **D**。

**关于“稳定 35% 以上”，如实说明**：在有可学习结构的数据上，系统能找到它、转化进冠军，并超过 35%（区制世界）；诊断书会指出还差哪个家族没用上（转化瓶颈 S2）并自动开影子验证。在两份真实开奖上，九个家族的信息探针、延续/转向矩阵、阶段库、区制记忆、近 4 万条窗口规律、整期排列与压缩率等逐项检验，都没有找到能在样本外复现的前推信息；样本内看到的高胜率段与打乱对照的波动幅度相同（第 17 章 §6）。这不是一句“都是随机”，而是每个数字都能复算的逐项检验结论；因此本方案不交付一个只在历史上好看的“35%”，而是交付：①永不劣于 XI 的主链；②每期都在找结构、一旦出现就自动转化和验证的系统；③每 500 期把差距、原因和下一步写清楚的诊断书。

## 1. 系统全景：一期开奖如何流过整个系统

```
开奖 t（结算事务内）
  ├─ 每个策略的冻结决定（出手或不出手）都被结算 → su2_live_decision
  ├─ 全部模型、校准器、原子网络、区制记忆、延续矩阵学习这一期（不出手的策略也学）
  └─ 主链：IPM 选中的成员（默认 XI）出手或 ABSTAIN
开奖 t+1 之前（预算 1.5 s）
  └─ 每个实时策略决定：最佳位置前三 + 校准后的命中概率；冻结
空闲时段（突发任务）
  ├─ 进化：一代一片；活动结束 → 委员会冠军进联赛（实时轨）
  ├─ 联赛→主链（IPM）、证书维护、保留规则
  └─ P50：信息探针追赶 → 500 期块统计 → 每 500 期一份升级诊断书 → 影子处方开设/结算 → 问题台账
检测报告导出
  └─ STORAGE_CENSUS.txt + UPGRADE_DIAGNOSIS.md/.json（≤64 KB + 256 KB）+ 有界的诊断证据
```
