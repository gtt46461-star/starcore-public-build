## B. 并发与提交故障矩阵

| 场景 | 注入方法 | 必须看到的结果 |
|---|---|---|
| 实时写锁被持有3s | 双连接或受控writer闸门；13研究任务同时ready | 不把busy计为FAULT、不全隔离；实时优先、研究公平恢复；无无限重试队列 |
| 旧owner晚提交 | 领取fence=n后强制租约过期，新owner取n+1，放行旧计算 | 旧成功与旧失败receipt均影响0行；新owner状态不被隔离/覆盖 |
| 领取成功后进程死 | 在claim、checkpoint、commit不同切点kill测试进程 | 从最后持久checkpoint恢复；不跳输入、不重复训练计数 |
| 提交后诊断抛错 | commit后注入观测/afterCommit错误 | 结果为已提交且诊断不全；无重做非幂等操作 |
| 磁盘满/约束/损坏 | SQLite故障适配层分别注入 | 独立故障类型和恢复路径；不得全部当busy |
| 取消与不可协作计算 | 中断、用户stop、超时不poll循环 | 旧owner撤权；关闭有界但未退出资源仍有所有者；不同时启动替身写同状态 |
| 重复结算与消息投递 | 同期同事件重复100次，反馈消费者重复执行 | 一个settlement、一个逻辑反馈、一份学习提交；outbox可至少一次投递但作用幂等 |
| 时钟回拨/跨重启 | wall clock前后跳、boot epoch改变 | 过期判断不靠跨boot elapsed直接比较；赛前时间不可信则显式拒绝，不能用缓存时间放行 |

## C. 每期链路验收

每期写一条可关联的终端事件：stream、issue/ordinal、首次接收、校验通过、开奖commit、分析请求、模型/特征边界、freeze deadline、实际freeze commit可验证状态、DecisionGate结果、settlement commit、feedback outbox、训练checkpoint、图表watermark。所有事件共享关联ID且分别记录wall/elapsed/boot。

输入对照包括：正常顺序、重复、乱序、同一期冲突、断网后补录、跨日期期号、时钟偏移、分析迟到、模型加载失败、没有合格证书。每个场景都要有明确终端结果，不能静默消失。没有赛前预测的历史期只生成训练样本与排除理由，不能产生伪造冻结记录。

在目标设备进行24h初测和72h终测：所有eligible实时期有终端状态；存在真实冻结的期结算率100%，重复结算0；冻结覆盖/时延另按总纲阈值验收。全日历期、在线eligible期、历史补录期分别给分母。不能以72/72结算冒充108个实时期都覆盖。

## D. 存储与恢复验收

至少使用三种起点：新安装并导入5000期；从当前约600MB数据库覆盖升级；构造或取得用户30GB级膨胀副本（没有该副本时该项NOT_RUN）。每种都测路径分类、所有者、引用根、活pin、临时预留、真实磁盘剩余。

连续试验包含：至少5次成功报告、5次取消、构建中杀进程、分享中删除请求、未读ZIP、坏归档、STALE_PAGE、活跃训练pin、旧备份恢复、WAL长读者、磁盘接近满。报告发布完成后10分钟内应释放无需重建/分享的工作副本或明确记录有期限的保护引用；不能要求任何时刻绝无snapshot，因为正在导出的快照有合法生命周期。

先停止无价值数据继续增长，再在引用验证和存储预算内分片瘦身。文件删除必须依据路径所有者与引用授权，不得按CACHE分类或文件名后缀即删。总空间同时计热库、WAL/SHM、索引、归档、训练checkpoint、报告ZIP、工作快照、临时复制与备份，不能把数据移到另一个目录后宣称回收成功。

72h常态空间与净增按总纲单一配置验收。超过预算的历史债务另列原值、已回收量、保护量、预计下一步；不能把所有超额文件标为PROTECTED后不再处理。保护闭包确实超过预算时触发有界限写与用户可理解状态，不能伪报稳定。

## E. 研究与模型能力验收

所有现有实际注册家族/专家/模型核至少做确定性冒烟，记录样本输入、结构/参数hash变化、有效预测输出、state恢复与消费者。不能为达到覆盖数临时注册空壳家族。新能力先有明确假设：什么输入结构、什么参数、什么更新规则、什么数据可以否证、如何比已有简单模型更有价值。

历史筛选使用固定输入快照与持久随机状态；同seed恢复结果等价。模型每期先predict再reveal/update，参数更新前后hash与loss样本绑定。反馈只来自允许角色；HOLDOUT/CONFIRM不回流创造器继续针对同段挑模型。

零信号、边际偏置、滞后、跨位置、短窗口变点、漂移反转、缺失与污染等合成场景，必须通过完整候选搜索→选择→资格流程，而非只给已知答案策略做一次命中检验。报告每场景试验数、种子、假阳性/检出率及置信区间。20次中的0次误报也不能证明误报率为0。检出周期应折算为ACT与日历期：15%频率下250次ACT期望约1667个日历机会，不能将250次ACT写成250分钟。

父子改进同时给配对同机会差、前向块稳定性、模型成本、校准、频率与真实样本量。未胜父代的子代保留失败原因并淘汰；用该失败反馈选择探索方向，但不能反复查看独立确认段调参。
