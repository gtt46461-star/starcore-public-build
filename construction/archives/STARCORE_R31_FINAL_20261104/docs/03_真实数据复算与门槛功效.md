# 真实数据复算与门槛功效

## 1. 本次真实可复算范围

从原报告DIAGNOSTIC_SCOPE.json提取了5000条开奖元数据，排序范围202610300771至202611030010，4999个相邻时间差均60000ms，每期均为1至10的排列；没有重复期号或重复开奖时间。脚本同时保留原数据的first_seen_at、fetch_time、raw_json和JSON路径。这里只验证报告内部一致性，未向上游独立核验，也未验证其开奖机制独立均匀。

原报告还包含73条SHADOW观察，72条已结算；按保存的单位置K3与开奖重算命中20次，即27.78%，描述性Wilson双侧95%区间18.76%至39.05%。没有将SHADOW计为REAL，也没有用这72条少量样本概括所有策略族或未来能力。

缺少原始SQLite页、安装APK、完整模型checkpoint和优化器状态，不能重新执行手机中每个生产模型的同一预测。虽然存在5000期历史数据，本次独立诊断不是全生产策略复现。

## 2. 一次固定协议的有限历史实验

配置文件：`evidence/review_experiment/replay_spec.json`；程序：`tools/run_historical_review.py`；全结果：`evidence/review_experiment/review_results.json`。程序只依赖Python与NumPy，执行后可生成全部100候选的结果表和已选候选逐期预测。

实验事先固定100个简单基线候选：10个位置×〔热频率4窗口、冷频率4窗口、前值邻号、固定1/2/3〕。窗口20/60/120/240，固定K3。前240期预热；第240至2999行作为SELECT；第3000至4999行作为HOLDOUT。每个目标t的特征严格只取数组[0,t)，预测后才揭示目标；阈值在SELECT按约15%机会拟合，进入后段后冻结，不按后段重新挑阈值或重选冠军。

这是一组简单可复现基线，不是R27/SU2的实现，不代表用户要求的完整创造能力。历史数组前序可用仅是回放假设，所有记录first_seen_at都晚于开奖，不能转化为历史真机赛前证据；它们更不能计入新的FUTURE样本。

生产版本要扩展到原模型/家族时，须从现有执行器导出完整状态，保存数据角色、搜索次数、候选曝光和随机数，再运行统一回放协议；不得把本脚本复制为新“高胜率工厂”交差。

## 3. 当前最长连败门的功效问题

源码`CertificateGateR27`要求FUTURE ACT≥250、命中率≥34%、最长连败≤6，同时还有序贯检验、校准、最坏块、ABI和配对对照等条件。本节只测“最长连败≤6”这一条。

若命中为独立伯努利(p)，令d[k]是尚未出现7连败且当前连败长度k（0至6）的概率质量。每次更新：新d[0]=p×sum(d)，新d[k]=(1-p)×旧d[k-1]。n次后的sum(d)就是这条规则的准确通过概率；程序通过小n全枚举核验此递推。

| 假设真实命中概率 | 250次ACT内最长连败≤6 | 600次ACT内最长连败≤6 |
|---:|---:|---:|
| 30% | 0.04698% | 0.0000008428% |
| 34% | 0.47002% | 0.00022433% |
| 37% | 1.75144% | 0.00544999% |
| 40% | 4.92972% | 0.06708440% |
| 45% | 16.99576% | 1.35184% |
| 50% | 37.30951% | 9.11708% |

这些是明确iid假设下的敏感性，既不是实盘频率，也不是全资格门检出力。它说明：当窗口足够长，固定“不得7连败”会高概率拒绝即使命中概率达到34%甚至40%的候选。它可能是业务风险偏好，但不能同时据此保证每天都会有高品质候选进主链。

R31应把检出优势的证据规则与风险暴露管理分开审计：研究所有门的联合功效与误报，按预注册规则决定是否建立新R31证据版本。旧V1结果留存且不静默改变。新门须在完整搜索流程零假设数据、植入信号数据、漂移与相关性场景中验证；连续观察采用已验证的序贯方法，或锁定固定评估时点，不反复看普通95%区间直到变绿。

## 4. 为什么图表不能保证高胜率

数值研究产物可以提供家族供给建议、算子成本与收益、原子消融贡献、结构变化后验、模型校准和父子配对证据。它们是否提升预测必须由实际消费者、冻结的应用版本与同源对照说明。增加面板数量或让曲线不为空不会自动提供新的预测信息。

建议每种研究建议实行版本化recommendation_id：生成依据→消费者读取→实际修改参数/预算→候选产物→独立比较→采纳/拒绝回执。未被读取或读取后未改变任何可执行内容的建议标记UNCONSUMED；改变了但未提升标记CONSUMED_UNPROVEN；只有独立比较支持时才标记VERIFIED_EFFECT。

## 5. 外部方法依据

- Howard等《Time-uniform, nonparametric, nonasymptotic confidence sequences》，https://arxiv.org/abs/1810.08240 。用于区分持续监测的时间一致证据与反复查看固定时点区间。
- Dwork等《Generalization in Adaptive Data Analysis and Holdout Reuse》，https://arxiv.org/abs/1506.02629 。用于解释自适应重复使用验证数据导致的选择偏差；本方案并未声称已经实现该论文的可重用留出算法。

上述依据只支持方法边界；具体应用的效果必须由本项目数据和代码执行证据证明。
